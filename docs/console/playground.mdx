title: Playground
description: Quote, submit, and inspect real image and video Jobs from Console without writing code.
---

[Console → Playground](https://yir.ai/console/playground) is a no-code way to try models. It calls the same Standard Gateway API your code uses, so what you see matches real integration behavior.

## Before you generate

1. Pick a model and set its parameters. Options come from the model's public contract; the quote tells you whether it can run right now.
2. Pick one of your API keys. Playground uses it by ID, and the browser never receives its secret. Expired keys are not listed.
3. Review the quote. It shows the current price for this exact request.

Playground uses the selected key's [Routing Profile](/docs/console/routing) and all of the key's limits. Requests are sent from Yir's web server, so a key with an IP allowlist must allow that server's address; the code examples run from your own environment instead.

## After you submit

Submitting creates a **real Job with real charges**. Result cards poll the Job and show its status, output, and charge. Open [Logs](/docs/console/logs) for the full record.

Recent results are restored from references stored in your browser. Clearing browser data does not delete Jobs; the complete history stays in Logs.

## Safe retries

Before submitting, Playground saves your draft and its idempotency key in this browser tab (without secrets or file contents). If the response is lost, retrying the unchanged request reuses the same key, so no duplicate Job is created. Reloading the tab restores the last unconfirmed draft but never submits it automatically. Changing the request or submitting again after a Job was returned creates a new Job.

A polling error keeps the last known status and polling continues; it does not mean the generation failed.

Results are kept for 7 days after the Job is created. Download anything you want to keep.
