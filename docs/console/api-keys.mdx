---
title: API Keys
description: Create, reveal, rotate, limit, expire, and revoke the API Keys that authenticate Gateway requests.
---

Manage keys in [Console → API Keys](https://yir.ai/console/api-keys). Every key authenticates Gateway requests with `Authorization: Bearer <YIR_API_KEY>`. See [authentication](/docs/getting-started/authentication).

## Default key

Every account has one default key. It cannot be revoked and never expires, but you can rotate its secret.

## Additional keys

Create extra keys for separate applications or environments. Each key has its own:

| Setting | Effect |
| --- | --- |
| **Routing Profile** | The default [routing](/docs/console/routing) for requests made with this key. Request-level `routing` can narrow it. Changing it applies to Jobs admitted afterward; admitted Jobs keep the routing frozen at admission. The key secret does not change. |
| **Monthly spend limit** | Optional cap for the current UTC month. New Jobs that would exceed it fail with `403 YIR_SPEND_LIMIT_EXCEEDED`; running Jobs are not interrupted. The key list shows spend so far. |
| **Expiration** | Never, or 30, 90, or 365 days from when you save. After expiry, requests fail with `401 YIR_UNAUTHORIZED`. You can extend an expired key at any time. |
| **IP allowlist** | Optional. Only requests from matching IPv4, IPv6, or CIDR ranges are accepted. Leave it off for dynamic egress, local development, or serverless platforms. |

Usage statistics and Logs are attributed per key.

## Secret actions

- **Reveal and copy.** You can reveal a key's secret again later in Console.
- **Rotate.** Issues a new secret for the same key. The old secret stops working as soon as rotation succeeds; the key's name, settings, and history are kept. If rotation fails, the old secret remains valid.
- **Revoke.** Permanently disables an additional key.

If a secret may have leaked, rotate or revoke the key immediately. An IP allowlist reduces the damage of a leak but does not replace rotation.

## Alerts

The [Alerts](/docs/console/alerts) page warns you when a key is within 7 days of expiring, has expired, or is close to or at its monthly spend limit.
