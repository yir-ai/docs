title: Routing Profile
description: 为绑定到每个 Routing Profile 的 API Key 设置默认的渠道偏好与渠道切换。
---

**Routing Profile** 保存绑定到它的所有 API Key 的默认路由。在 [Console → 路由](https://yir.ai/zh/console/routing)中管理。

## Profile 的设置

| 设置 | 作用 |
| --- | --- |
| **模式** | **价格优先**按估价从低到高选择渠道；**速度优先**按近期实测的生成耗时从快到慢选择，近期样本不足的渠道按价格排序。不同产品需要不同取舍时，可以建多个 Profile 分别绑定 Key。 |
| **渠道切换** | 尝试被确认失败后，是否允许 Yir 切换到其他渠道。建议开启。 |

每个账户都有一个默认 Profile。你可以创建更多 Profile、重命名或编辑，并删除不再需要的 Profile。每个 API Key 绑定一个 Profile，在创建或编辑 Key 时选择。Profile 列表显示每个 Profile 关联的 Key 数量。

较早创建的 Profile 可能还带有模型或渠道限制。这些限制会显示在 Profile 上并继续生效；请求级路由只能收窄、不能放宽它们。

不支持自定义渠道顺序，Yir 会在合格渠道中自动选择。

## 按请求覆盖

请求中的 `routing` 对象在该请求中优先于 Profile：可以修改 `preference` 和 `fallback`，用 `only` 限定渠道，并选择 `variants`。完整规则见[路由与渠道切换](/zh/docs/concepts/routing)。

路由不能指定凭据，也不能绕过认证、余额、支出上限、规格校验或尝试次数限制。
