title: Playground
description: 在浏览器不接触 API Key Secret 的前提下，报价、提交并检查真实图片和视频生成任务。
---

Playground 是 Yir 图片和视频生成的零代码调试入口。报价、文件上传计划与确认、生成提交和任务查询均通过服务端调用 Standard Gateway API。

## 生成前

选择模型、输出规格和一条逻辑 Yir API Key。Console 只按 ID 使用所选 Key，浏览器不会收到它的 Secret。

模型选项来自 Go 单向生成的公共参数合同，不代表当前都有可用供应；以本次完整请求的报价结果为准。服务端每次使用所选 Key 的当前 Secret，撤销、轮转和 IP 白名单仍由 Gateway 校验。调试台请求的来源是 Web 服务端，因此白名单须允许其实际出口地址；外部代码示例从你的运行环境发起请求，可能使用不同出口。

Playground 会在提交前展示安全报价。报价基于当前请求和合格供应估算，不代表已创建 Job，也不承诺计划中的每条路线都会被提交。

## 路由控制

调试台使用所选 API Key 绑定的 RoutingProfile。需要修改策略时前往 API Keys 页面；单次请求的高级路由用法以 Standard API 文档为准。

用户不能选择 AccessProvider、Credential、内部接入路径、评分或任意 Attempt 数量。

## 提交后

提交会创建真实 Yir Job，并可能产生真实费用。结果卡片轮询公开 Job 接口，只展示该接口提供的结果与费用。详细渠道与尝试记录可前往日志页面查看。提交响应不确定时，同一未修改请求的再次提交复用幂等键；修改请求或已成功取得 Job 后再次提交会创建新的任务。

提交前，调试台将草稿和幂等键保存在当前标签页的会话存储中，不保存 API Secret 或文件内容。刷新后恢复属于当前用户 Key 的最近一笔未确认草稿，但不会自动提交。相同请求与 Key 重试时复用原幂等键。关闭标签页或清除会话存储会移除恢复数据，此时请先检查日志，再决定是否创建替代任务。浏览器无法保存恢复记录时会阻止提交。

报价与轮询错误会通过 Yir 标准错误提示展示。轮询失败时保留上次已知的 Job 状态并继续查询，不会把网络查询失败当作生成失败。

重试未确认且未修改的提交不要求重新取得报价，因为原 Job 可能已经占用余额。Gateway 仍会校验 Key 并处理重复幂等键；修改请求后须重新报价。

最近记录通过当前浏览器保存的任务引用恢复，再使用原 Key 查询公开 Job；更换浏览器或清除本地记录不会删除服务端任务，完整任务历史仍在日志页面。

结果保留至任务创建后第 7 天；已有结果可能更早到期。需要长期保存的内容应在保留期结束前下载。
