---
title: 调试台
description: 无需写代码，在 Console 中报价、提交并查看真实的图片与视频 Job。
---

[Console → 调试台](https://yir.ai/zh/console/playground)让你无需写代码即可试用模型。它调用的就是你代码中使用的 Standard Gateway API，因此看到的行为与真实集成一致。

## 生成之前

1. 选择模型并设置参数。选项来自模型的公开合同；报价会告诉你当前能否执行。
2. 选择一个 API Key。调试台按 ID 使用它，浏览器不会拿到 Secret。已过期的 Key 不会出现在列表中。
3. 查看报价，即当前这个具体请求的价格。

调试台使用所选 Key 的 [Routing Profile](/zh/docs/console/routing) 和该 Key 的所有限制。请求从 Yir 的 Web 服务器发出，因此启用了 IP 白名单的 Key 必须允许该服务器地址；代码示例则从你自己的环境发出。

## 提交之后

提交会创建**真实 Job 并产生真实费用**。结果卡片会轮询 Job，显示状态、输出和收费。完整记录见[日志](/zh/docs/console/logs)。

最近的结果通过浏览器中保存的引用恢复。清除浏览器数据不会删除 Job，完整历史保留在日志中。

## 安全重试

提交前，调试台会把草稿及其幂等键保存在当前浏览器标签页中（不含 Secret 或文件内容）。如果响应丢失，重试未修改的请求会复用同一个键，不会产生重复 Job。刷新标签页会恢复最近一次未确认的草稿，但不会自动提交。修改请求，或在已返回 Job 后再次提交，都会创建新的 Job。

轮询出错时会保留最后已知状态并继续轮询，这并不表示生成失败。

结果自 Job 创建起保留 7 天，请及时下载需要保存的内容。
