---
title: 告警
description: 查看需要处理的账户状况，例如余额不足、Key 限额、Webhook 投递失败和失败率偏高。
---

[Console → 告警](https://yir.ai/zh/console/alerts)按紧急程度列出账户当前需要处理的问题，每条告警都链接到可以处理它的页面。

| 告警 | 级别 | 触发条件 |
| --- | --- | --- |
| 余额不足 | 警告；余额耗尽时为严重 | 可用余额低于你设置的低余额阈值。余额为零时无法提交新 Job。 |
| Key 支出上限 | 接近时为警告，达到时为严重 | 某个 API Key 接近或达到月度支出上限。达到上限后，该 Key 的新 Job 会被拒绝。 |
| Key 已过期 | 严重 | 某个 API Key 已过期，其请求被拒绝。 |
| Key 即将过期 | 警告 | 某个 API Key 将在 7 天内过期。 |
| Job 失败率偏高 | 警告或严重 | 近期已结束的 Job 中失败比例偏高。 |
| Webhook 投递失败 | 警告 | 某个回调地址最近一次投递失败。 |

页面还提供最近 7 天失败 Job 与全部已结束 Job 的对比图。

问题解决后告警会自动消失。低余额阈值在账单页设置，并可在每次余额不足时发送一封提醒邮件。Yir 不会自动充值或自动扣款。
