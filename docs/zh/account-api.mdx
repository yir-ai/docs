**Account API（账户 API）**只操作你自己的 Yir 账户。**Gateway API（网关 API）**负责图片、视频任务。Yir 内部的 **Admin API（运营后台 API）**是独立系统，不属于这两套公共 API。

| API | 基础地址 | 凭据 |
| --- | --- | --- |
| Gateway API | `https://gateway.yir.ai/v1` | 网关 Key（`yir_sk_…`） |
| Account API | `https://api.yir.ai/account/v1` | 账户 Key（`yir_ak_…`） |

两类 Key 不能混用。既有 API Key 保持为网关 Key，权限不变。两套 API 都使用 `Authorization: Bearer <key>`；Key 只保存在服务端，不放进浏览器代码。

## 创建账户 Key

进入 **Console → API Keys → 创建 API Key**，选择**账户 Key**，填写名称、权限和可选的有效期：

- **只读**（默认）：查询分析数据、日志、路由配置、Webhook 和告警设置。
- **读取并修改设置**：另外允许创建、修改和删除路由配置及 Webhook，修改告警。

账户 Key 可以在 Console 改名、设置 IP 白名单和有效期、轮转或撤销。用途和权限在创建时确定；需要改变权限时创建替代 Key。轮转保留权限及有效期，使旧 Secret 失效。账户 Key 没有生成预算或路由绑定。

创建、查看 Secret、轮转和撤销 Key，修改消费限额，以及支付和身份修改，仍需登录 Console。账户 Key 不能给自己提权，也不能访问内部运营后台。

## TypeScript

使用 `@yir-ai/sdk/server` 中的账户客户端：

```ts
import { createAccountClient } from '@yir-ai/sdk/server';

// 读取 YIR_ACCOUNT_API_KEY，不回退到网关 Key。
const account = createAccountClient();
const analytics = await account.analytics.get({
  from: '2026-10-01T00:00:00Z',
  to: '2026-10-08T00:00:00Z',
  timezone: 'UTC',
  group_by: 'model',
});
const profiles = await account.routingProfiles.list();
// 需要修改设置权限；先明确要修改的配置。
async function preferSpeed(profileId: string) {
  return account.routingProfiles.update(profileId, { default_preference: 'speed' });
}
```

account, err := yir.NewAccountClient(os.Getenv("YIR_ACCOUNT_API_KEY"), yir.ClientOptions{})

## 接口

以下路径均相对于 Account API 基础地址。所有记录限定在 Key 所属账户内，传入其他人的资源 ID 不会获得访问权。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/analytics` | 任务数、成功率、耗时、实收、时间序列和分组 |
| GET | `/logs` | 筛选和分页查询任务 |
| GET | `/logs/{id}` | 任务详情与诊断 |
| GET / POST | `/routing-profiles` | 列出 / 创建路由配置 |
| PATCH / DELETE | `/routing-profiles/{id}` | 修改 / 归档路由配置 |
| GET / POST | `/webhook-endpoints` | 列出 / 创建回调端点 |
| GET / PATCH / DELETE | `/webhook-endpoints/{id}` | 读取 / 修改 / 删除回调端点 |
| GET | `/webhook-endpoints/{id}/deliveries` | 回调投递记录 |
| GET / PUT | `/alerts/settings` | 读取 / 替换邮件告警设置 |
| GET / PUT | `/wallet/low-balance-alert` | 读取 / 替换低余额提醒策略 |

分析查询支持 `from`、`to`、`timezone`、`core_model`、`attempt_provider` 和 `group_by`（`model`、`provider`、`api_key`、`status`）。解释结果时检查返回的 `coverage` 和样本数；缺失指标不等于零。日志支持 `page_offset`、`page_limit`、时间和状态筛选；查询失败任务时，可以通过 `exclude_error_code=YIR_CONTENT_REJECTED` 排除内容拦截。

```sh
curl 'https://api.yir.ai/account/v1/analytics?group_by=model' \
  -H "Authorization: Bearer $YIR_ACCOUNT_API_KEY"
```

REST 成功响应为 `{"code":200,"message":"success","data":...}`，SDK 自动解包 `data`。错误使用非成功 HTTP 状态及 `code`、`message`。Key 错误、过期或撤销返回 401；只读 Key 修改设置返回 403。响应属于私有数据，不可缓存。SDK 不自动重试设置写入；创建操作结果不明时，应先列出资源核对，再决定是否重试。

完整请求和响应结构见独立的 [Account API 合同](https://github.com/yir-ai/sdk/blob/main/spec/account-openapi.json)，与 Gateway API 合同分开维护。
