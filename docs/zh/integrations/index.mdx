---
title: 选择接入方式
description: 对比 Standard API、官方 SDK、Vercel AI SDK 与 OpenAI 兼容接口，按现有技术栈选择接入 Yir 的方式。
---

这些方式最终都调用同一个 Standard API，Job、路由和计费规则完全一致，区别只在调用方式和能用到的功能。

| 你的情况 | 推荐方式 | 说明 |
| --- | --- | --- |
| 新项目，任意语言 | Standard API（REST） | 直接发 HTTP 请求，功能最完整。从[快速上手](/zh/docs/getting-started/quickstart)开始，接口细节见 [API 参考](/zh/docs/reference)。 |
| 后端用 TypeScript 或 Go | [SDK](/zh/docs/integrations/sdk) | 在 Standard API 之上处理轮询退避、错误类型、文件上传和 Webhook 验签。 |
| 已在用 Vercel AI SDK | [Vercel AI SDK](/zh/docs/integrations/vercel-ai-sdk) | 用 `generateImage` 与视频函数调用 Yir，现有代码改动最少。 |
| 已按 OpenAI Images、Sora 或 new-api 对接 | [OpenAI 兼容与 new-api](/zh/docs/integrations/openai-compatibility) | 只换 Base URL 和 Key。同步等待结果，不支持 Webhook 和完整路由控制。 |
| 在 Claude Code、Codex 等编程 Agent 里生成 | [Agent Skill](/zh/docs/integrations/agent-skill) | 用自然语言让 Agent 生成图片和视频，Skill 代为调用 Standard API。 |

拿不准时，选 Standard API 或 SDK。所有方式都只用 Yir API Key 认证，见[身份认证](/zh/docs/getting-started/authentication)。
