官方 SDK 开源于 [yir-ai/sdk](https://github.com/yir-ai/sdk)，覆盖报价、生成、Job 等待、取消、文件上传和 Webhook 校验。你也可以直接调用 REST API，[快速上手](/zh/docs/getting-started/quickstart)使用的就是 cURL。已按 OpenAI Images、Sora 或 new-api 对接的系统，可通过 [OpenAI 兼容](/zh/docs/integrations/openai-compatibility)无需改代码接入。

| 语言 | 包 | 发布版本 |
| --- | --- | --- |
| TypeScript | `@yir-ai/sdk` | [npm](https://www.npmjs.com/package/@yir-ai/sdk) |
| Go | `github.com/yir-ai/sdk/go` | [GitHub](https://github.com/yir-ai/sdk/tags) |

两个客户端都从服务端读取 `YIR_API_KEY`，默认地址为 `https://gateway.yir.ai`。请只在服务端使用；TypeScript 包的浏览器入口只包含纯函数和类型。

## 安装

<CodeGroup>

```sh TypeScript
pnpm add @yir-ai/sdk
```

```sh Go
go get github.com/yir-ai/sdk/go@latest
```

</CodeGroup>

TypeScript 包为 ESM，需要支持原生 `fetch`、Web Crypto 和 `Blob` 的运行时（Node.js 22 及以上）。Go 模块需要 Go 1.25 及以上。

## 端到端生成一张图片

<CodeGroup>

```ts TypeScript
import { createNodeYirClient } from "@yir-ai/sdk/server";
import type { StandardImageGenerationRequest } from "@yir-ai/sdk/shared";

const client = createNodeYirClient(); // reads YIR_API_KEY

const request: StandardImageGenerationRequest = {
  model: "openai/gpt-image-2",
  input: { type: "text", prompt: "A quiet observatory above a sea of clouds" },
  parameters: { resolution: "1K", aspect_ratio: "1:1", n: 1 },
};

const quote = await client.quoteImage(request);
if (!quote.supply.available) {
  throw new Error("No supply for this request");
}
console.log(quote.primary.amount); // estimate, not a ceiling

// Persist the request and key before submitting so you can recover.
// Optional: add max_cost to cap the Job's charge.
const saved = { request, idempotencyKey: crypto.randomUUID() };

const job = await client.submitImage(saved.request, saved.idempotencyKey);
const done = await client.waitForJob(job.id, { timeoutMs: 5 * 60_000 });

console.log(done.status, done.billing?.total_charged_by_yir);
if (done.result?.availability === "available") {
  console.log(done.result.files[0].url); // copy to your own storage
}
```

```go Go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Minute)
defer cancel()

client, err := yir.NewClient(os.Getenv("YIR_API_KEY"), yir.ClientOptions{})
if err != nil {
	return err
}

request := yir.GenerationRequest{
	Model:      "openai/gpt-image-2",
	Input:      yir.GenerationInput{Type: "text", Prompt: "A quiet observatory above a sea of clouds"},
	Parameters: map[string]any{"resolution": "1K", "aspect_ratio": "1:1", "n": 1},
}

quote, err := client.QuoteImage(ctx, request)
if err != nil {
	return err
}
if !quote.Supply.Available {
	return errors.New("no supply for this request")
}

// Persist the request and key before submitting so you can recover.
// Optional: set MaxCost to cap the Job's charge.
saved := yir.SubmitRequest{GenerationRequest: request}
key := "order-123-image-1"

job, err := client.SubmitImage(ctx, saved, key)
if err != nil {
	return err // An unknown outcome is not a failure: retry with the same saved request and key.
}

final, err := client.WaitJob(ctx, job.ID, yir.WaitOptions{})
var failed *yir.JobError
if errors.As(err, &failed) {
	return fmt.Errorf("job %s ended %s", failed.Job.ID, failed.Job.Status)
}
if err != nil {
	return err // Local timeout: the Job keeps running. Resume with job.ID later.
}
fmt.Println(final.Status)
if final.Billing != nil {
	fmt.Println(final.Billing.TotalChargedByYir)
}
if final.Result != nil && final.Result.Availability == "available" && len(final.Result.Files) > 0 {
	fmt.Println(final.Result.Files[0].URL) // copy to your own storage
}
```

</CodeGroup>

Go 代码片段是一个返回 `error` 的函数体，需要导入 `context`、`errors`、`fmt`、`os`、`time` 和 `yir "github.com/yir-ai/sdk/go"`。仓库中有[经过编译检查的示例](https://github.com/yir-ai/sdk/blob/main/go/client_example_test.go)。

## API 一览

| 能力 | TypeScript | Go |
| --- | --- | --- |
| 报价 | `quoteImage`、`quoteVideo`、`quoteBatch` | `QuoteImage`、`QuoteVideo`、`QuoteBatch` |
| 提交 | `submitImage`、`submitVideo` | `SubmitImage`、`SubmitVideo` |
| Job | `getJob`、`getJobStatus`、`cancelJob`、`waitForJob` | `GetJob`、`GetJobStatus`、`CancelJob`、`WaitJob` |
| 文件 | `createFiles`、`uploadFile`、`createAndUploadFile`、`getFile`、`completeFile`、`waitForFileReady`、`getFileContentURL` | `CreateFiles`、`UploadFile`、`CreateAndUploadFile`、`GetFile`、`CompleteFile`、`WaitForFileReady`、`GetFileContentURL` |
| Webhook | `verifyWebhookSignature`、`constructWebhookEvent` | `VerifyWebhookSignature`、`ConstructWebhookEvent` |
| 模型 | `getModelContracts`、`getModelContract`、`getModel` | `GetModelContracts`、`GetModelContract`、`GetModel` |

TypeScript 中的 `uploadFile`、`createAndUploadFile`、`waitForFileReady` 是从 `@yir-ai/sdk/server` 导出的函数，不是 client 方法，调用时把 client 作为第一个参数传入，例如 `createAndUploadFile(client, metadata, data, key)`。Go 中它们是 client 方法。见[输入文件](/zh/docs/guides/input-files#使用-sdk)。

## 需要了解的行为

- **幂等键。** API 要求每个生成请求都携带幂等键。省略键参数时，SDK 会为这次调用生成随机键，它只能保护这一次 HTTP 调用；再次无键调用可能创建另一笔收费 Job。请传入自己持久化的键，并在进程崩溃或结果未知后与完整请求一起复用。SDK 不会自动重试提交。
- **等待。** `waitForJob` / `WaitJob` 长轮询状态接口（每次最多挂起 20 秒；Gateway 不挂起时回退为 5 秒、10 秒、20 秒退避），结束时读取一次完整 Job。超时或中止只停止本地等待，Job 继续运行；用保存的 ID 继续即可。
- **错误。** API 错误提供 `status`、`code`、`retryable`、`action`；字段级的 `YIR_INVALID_REQUEST` 还带 `details`，给出无效字段、稳定原因码和允许值。失败或取消的 Job 会抛出携带完整 Job 的 `YirJobError`（TypeScript）或 `JobError`（Go）。请按 `code` 分支，不要依赖错误消息。见[错误码](/zh/docs/production/error-codes)。
- **校验。** SDK 不内置模型目录。用 `getModelContracts` / `GetModelContracts` 获取（或据此生成 `models.ts`）并传入后做本地校验，否则由 Gateway 校验。新增模型无需发布 SDK。见[模型与参数](/zh/docs/models)。
- **Job ID** 是不透明字符串，按返回值保存，不要解析。

## 升级

**TypeScript 0.3.0 / Go 0.4.0。** 等待改为退避轮询（5 秒、10 秒、20 秒），不再每 2 秒查询一次；如需固定间隔，设置 `pollIntervalMs` / `WaitOptions.PollInterval`。新增 `constructWebhookEvent` / `ConstructWebhookEvent`，调用签名不变。

**TypeScript 0.3.1 / Go 0.4.1。** `constructWebhookEvent` / `ConstructWebhookEvent` 同样拒绝 `getJob` / `GetJob` 不接受的 Job ID（须匹配 `^[1-9][0-9]*$`）；`pollDelayMs` / `PollDelay` 的 `poll` 参数为刚完成那次查询的 0 基序号。调用签名不变。

**TypeScript 0.3.2 / Go 0.4.2。** TypeScript 按 Unicode 码点计算 20,000 字符的提示词上限，含 emoji 的提示词不再被提前拒绝。Go 的 `Quote.Validate` 会拒绝 `supply` 与价格不一致的报价，与 TypeScript 一致。调用签名不变。

**TypeScript 0.4.0 / Go 0.5.0（URL 参考不再可用）。** 每个媒体参考都必须使用 `file_id`，当时外部参考 URL 会被拒绝（Gateway 现已重新接受公开 HTTPS `url` 参考，见[输入文件](/zh/docs/guides/input-files#公开-url)）。请先通过 [Files API](/zh/docs/guides/input-files) 上传原始字节。上传辅助函数会等待文件变为 `ready`（默认超时五分钟），可用 `waitForFileReady` / `WaitForFileReady` 按已保存的文件 ID 继续等待。Vercel AI SDK 适配器只接受字节，URL 输入需先在应用中下载。报价校验也接受服务端授权的无上限供应。

**TypeScript 0.4.1 / Go 0.5.1。** 与上一版兼容。Go 的 `Job` 新增 `FinalProvider`、`URLs`、`Usage`，`JobBilling` 新增费用明细，与 TypeScript 一致。新增错误码常量（`YIR_ERROR_CODES` / `ErrCode*`），User-Agent 会报告 SDK 版本。TypeScript 的 `cancelJob` 支持中断信号，返回的不是所请求的 Job 时会拒绝。内置模型合同与当前服务端一致：新增 `alibaba/qwen-image-2.1`，Gemini Omni 接受 `duration`，`wan-2.6` 最多 5 个参考，移除 `kie/gemini-omni-video` 别名。只影响基于内置目录的校验。

**TypeScript 0.5.0 / Go 0.6.0。** `getModel` / `GetModel` 读取模型的市场详情；`getFileContentURL` / `GetFileContentURL` 返回 ready 文件的短期签名 URL，且不跟随跳转，API Key 不会发给存储端。请求该 URL 时不要带 Gateway 凭据。TypeScript 中自行实现 `YirClient` 或 `YirFileClient` 的代码需要补上新方法，自定义传输需要支持 `redirect: "manual"` 才能使用 `getFileContentURL`；使用 `createNodeYirClient` 的调用方无需改动。

**TypeScript 0.6.0 / Go 0.7.0（不兼容）。** 支持显式 `billing_mode: "actual"`。`ComputeCharge` 只描述由 Yir 计费的托管供应，`amount` 不再为空（Go 的 `Amount` 从 `*string` 改为 `string`）。未传模型目录时，本地校验只检查协议骨架，模型规则交给 Gateway；比 SDK 新的字段和枚举值原样通过，类型放宽为 `(string & {})`，穷举的 `switch` 需要 default 分支。

**TypeScript 0.7.0 / Go 0.8.0（不兼容）。** 等待默认长轮询（`statusWaitSeconds` / `WaitOptions.StatusWait`，20 秒）。比 SDK 新的 Job 与文件状态按进行中处理。验签通过但不是终态 Job 的 Webhook 报告 `unsupported_event`，请返回 2xx 确认。模型目录只作用于其描述的模型。TypeScript 默认把每个 Gateway 请求限制在 30 秒（`timeoutMs`），没有错误码的错误体使用 `http_error`。

**TypeScript 0.8.0 / Go 0.9.0。** 兼容。`result.content_safety` 说明交付结果是否通过 NSFW 检测，`routing.preference` 新增 `speed`；`balanced` 是 `cost` 的弃用别名。

**TypeScript 0.9.0 / Go 0.10.0。** 未单独发布，随下一版一起发布。报价删除已废弃的 `max`、`single_attempt_upper_bound`、`has_verifiable_upper_bound` 与 `supply.requires_max_cost`（Gateway 仍为旧版 SDK 返回），删除 `billing.savings`，模型合同不再带 `policy`，`RoutingPreference` 不再列出 `balanced`，TypeScript 删除 `DEFAULT_POLL_INTERVAL_MS`。

**TypeScript 0.10.0 / Go 0.11.0（不兼容）。** 从 TypeScript 0.8 / Go 0.9 升级请先看上一条。移除内置模型目录：用 `getModelContracts` / `GetModelContracts` 获取并据此校验（`validateGeneration(operation, request, catalog)` / `ValidateGenerationWithCatalog`）；TypeScript 删除 `@yir-ai/sdk/model-contracts` 入口。Job ID 是不透明字符串。字段级的 `YIR_INVALID_REQUEST` 错误带 `details`。TypeScript 的参考素材除 `file_id` 外也接受 `url`。未配置目录时，报价可能把别名回显为 `creator/model` 形式的规范 ID。Gateway 现在要求 `parameters`，拒绝顶层旧参数与 `input.image`，`resolution`、`aspect_ratio` 只接受合同写法，公开别名也已精简，建议使用规范 ID。Veo 3.0 与 Gemini Omni 预览版已下架。

**TypeScript 0.10.1 / Go 0.11.1。** 兼容。`Quote.parameters`（TypeScript 类型 `QuoteParameters`）只回显模型合同声明的参数，图片报价和没有该参数的视频模型不再出现 `duration`、`generate_audio`；`Job.parameters` 自创建起携带同样的回显。模型合同参数只有没有默认值时才 `required`，本地校验不变。模型合同接口返回 `ETag` 与 `Cache-Control: private, max-age=300`，并对 `If-None-Match` 回 304。

完整发布说明见 [TypeScript](https://github.com/yir-ai/sdk/blob/main/typescript/CHANGELOG.md) 与 [Go](https://github.com/yir-ai/sdk/blob/main/go/CHANGELOG.md) 更新日志。

**从 0.1.0 升级。** TypeScript 0.2 与 Go 0.2 移除了内置模型清单和客户端价格表，等待改为轮询状态接口（`onPoll` / `OnPoll` 现在接收状态摘要）。Go 0.3.0 把幂等键参数改为可变参数。升级前请阅读[迁移指南](https://github.com/yir-ai/sdk/blob/main/typescript/docs/parameter-contracts.md)。

Python 没有官方 SDK，可直接调用 REST；[Webhook 指南](/zh/docs/production/webhooks)提供了 Python 签名校验示例。
