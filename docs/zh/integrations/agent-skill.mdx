官方 `yir` Skill 让 Claude Code、Codex 等编程 Agent 通过 Yir 生成图片、编辑本地图片和生成视频。它会列出模型和价格、报价、提交 Job、等待结果并把文件保存到本地。Skill 开源在 [yir-ai/skills](https://github.com/yir-ai/skills)。

需要 Node.js 18 或更高版本，自带脚本无其他依赖。

## 安装

Claude Code 可以作为插件安装，之后用 `/plugin marketplace update yir-ai` 更新：

```sh
/plugin marketplace add yir-ai/skills
/plugin install yir@yir-ai
```

要一次装到 Claude Code 和 Codex，可以用 [skills](https://github.com/vercel-labs/skills) 命令行（Windows 上加 `--copy`）：

```sh
npx skills add yir-ai/skills -a claude-code -a codex
```

也可以把 `skills/yir` 复制到 Agent 的 skills 目录。下文直接运行脚本的示例按 Claude Code 的安装路径书写。

<CodeGroup>

```sh Claude Code
git clone https://github.com/yir-ai/skills.git
cp -r skills/skills/yir ~/.claude/skills/yir
```

```sh Codex
git clone https://github.com/yir-ai/skills.git
cp -r skills/skills/yir ~/.agents/skills/yir
```

</CodeGroup>

项目内也可以放：Claude Code 读 `.claude/skills/`，Codex 读 `.agents/skills/`。其他支持 `SKILL.md` 的 Agent 指向同一目录即可。

## 设置 API Key

在 Yir Console 创建 API Key，并在 Agent 运行的环境中设置，见[身份认证](/zh/docs/getting-started/authentication)。

```sh
export YIR_API_KEY="..."
```

Job 费用从 Yir 钱包扣除。

## 使用

直接用自然语言告诉 Agent：

- “用 Yir 生成一张 16:9 的黄昏灯塔主图。”
- “用 Yir 把 ./first-frame.png 做成 5 秒视频。”

也可以从安装目录直接运行脚本（以下以 Claude Code 为例）：

```sh
# 文生图
node ~/.claude/skills/yir/scripts/yir.mjs image -m openai/gpt-image-2 --prompt "a lighthouse at dusk" -p aspect_ratio=16:9

# 文生视频
node ~/.claude/skills/yir/scripts/yir.mjs video -m bytedance/seedance-1.5-pro --prompt "waves at night" -p duration=4
```

结果默认保存到 `./yir-output`，每个结果旁附一个 `.json` 文件，记录提示词、参数、渠道、Job ID 和费用。运行 `node ~/.claude/skills/yir/scripts/yir.mjs --help` 查看全部命令，包括 `models`、`quote` 和 `job <id> --wait --download`。

## 从 fal 迁移代码

让 Agent 把现有的 fal 调用换成 Yir（“把这个项目里的 fal 调用换成 Yir，告诉我有什么变化”）。Skill 会逐个把 fal 请求翻译成等价的 Yir 请求，并在改代码前列出全部差异：

- 代码没设置、由 fal 默认生效的参数会被显式写出，产出保持不变（例如 Seedance 保持有声）。
- `num_images` 大于 1 时，每个输出对应一个 Job。
- Yir 无法完全对应的选项（如 fal 的自动时长、fal 专有设置）会列出来由你决定，不做悄悄的近似。

Agent 会先给出变化和每个 Job 的报价，你确认后才修改代码。也可以自己翻译单个请求，`--quote` 只报价、不创建 Job：

```sh
node ~/.claude/skills/yir/scripts/from-fal.mjs bytedance/seedance-2.5/image-to-video --json '{"prompt":"a paper boat","image_url":"https://example.com/a.png","duration":"5"}' --quote
```

`--list` 列出哪些 fal 端点有对应的 Yir 模型。

## 批量生成素材

做落地页、演示文稿或文章时，可以直接要一整套（“主图、三张功能图和一段 5 秒演示视频，总价不超过 $2”）。Skill 会写出计划文件，作为一个批次运行：

```sh
# 校验每个任务并汇总报价，不提交
node ~/.claude/skills/yir/scripts/yir.mjs batch plan.json --dry-run --out ./assets

# 设定花费上限后运行
node ~/.claude/skills/yir/scripts/yir.mjs batch plan.json --max-total 2.00 --out ./assets
```

每次提交前，Skill 会用已完成任务的实际扣费核对 `--max-total`。再次运行同一命令会接着跑：已完成的任务跳过，已提交的任务不会重复创建。计划文件格式见 Skill 的 [SKILL.md](https://github.com/yir-ai/skills/blob/main/skills/yir/SKILL.md)。
