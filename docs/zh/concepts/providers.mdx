---
title: 服务商与托管供应
description: Yir 如何通过托管的服务商账户提供生成能力，以及这对你的凭据意味着什么。
---

**服务商**（或渠道）是实际运行模型的上游平台：模型原厂自己的 API，或经过认证的第三方供应商。Yir 只列出已接入并验证过的渠道和模型。

## 托管供应

Yir Cloud 的每个 Job 都在 Yir 托管并付费的服务商账户上运行。你只需为一个 Yir 钱包充值；服务商账户、容量和结算都由 Yir 负责，并且只对已交付的结果向你收费（见[报价与计费](/zh/docs/concepts/billing)）。

某个模型列出了某个渠道，并不保证它此刻能执行你的请求。能否执行取决于渠道支持的参数、当前可用性，以及你设置的 `max_cost`。报价会告诉你当前是否有渠道能处理某个具体请求。

## 你的凭据

- 请求只使用 Yir API Key。
- Yir 不接受自带的服务商 Key（BYOK）、自定义 Base URL、自定义服务商或模型映射。
- 服务商凭据只保存在 Yir 服务端，不会出现在响应、日志或 Webhook 中。

## 选择渠道

通过 `routing` 对象优先低价、限定渠道或选择渠道版本，见[路由与渠道切换](/zh/docs/concepts/routing)。
