**渠道**是实际运行模型的上游平台：模型厂商自己的官方 API，或经过认证的第三方平台。Yir 只列出已接入并验证过的渠道和模型。

## 托管供应

Yir Cloud 的每个 Job 都在 Yir 托管并付费的渠道账户上运行。你只需为一个 Yir 钱包充值；渠道账户、容量和结算都由 Yir 负责，并把渠道的实际账单按你的折扣照实转收，渠道未计费的尝试不收费（见[报价与计费](/zh/docs/concepts/billing)）。

某个模型列出了某个渠道，并不保证它此刻能执行你的请求。能否执行取决于渠道支持的参数、当前可用性，以及你设置的 `max_cost`。报价会告诉你当前是否有渠道能处理某个具体请求。

## 你的凭据

- 请求只使用 Yir API Key。
- Yir 不接受自带的渠道 Key（BYOK）、自定义 Base URL、自定义渠道或模型映射。
- 渠道凭据只保存在 Yir 服务端，不会出现在响应、日志或 Webhook 中。

## 选择渠道

通过 `routing` 对象优先低价、限定渠道或选择渠道版本，见[路由与渠道切换](/zh/docs/concepts/routing)。

同一渠道可能为某个模型提供多个版本，价格和可承接的参数各不相同，同一请求不一定能在每个版本上执行。见[不同版本可承接的请求不同](/zh/docs/concepts/routing#不同版本可承接的请求不同)。
