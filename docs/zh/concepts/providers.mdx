---
title: 服务商与托管供应
description: 了解 Yir Cloud 的托管供应、服务商选择和凭据边界。
---

**服务商（Provider）**是为图片、视频等 AI 生成任务提供实际算力和 API 的上游平台。Yir 只展示并接入经过 Yir 认证且受支持的服务商和能力。

## 托管供应

Yir Cloud 通过平台管理的服务商账号提供生成能力。提交任务前需要充值 Yir 钱包；每次向服务商提交前都需要通过余额检查和预授权，按已确认的可计费事实结算。

你可以通过路由配置表达服务商偏好。目录中存在某个服务商，不代表其全部模型和规格随时可执行；实际执行取决于当前供应、规格支持和你的授权预算。

## Credential 安全

任务请求只使用 Yir API Key。上游 Credential 由 Yir 在服务端管理，不会返回给用户。Yir Cloud 不接收用户自有上游 API Key，不支持 BYOK。

## 只支持已接入的服务商

Yir 不接受任意 Base URL、自定义 Provider 或用户自行映射模型。只有受支持的服务商和能力可以参与路由与故障转移。
