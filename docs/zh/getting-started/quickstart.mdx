title: 快速上手
description: 使用 Yir Standard API 生成第一张图片，跟踪 Job 并下载结果。
---

本文用 cURL 调用 GPT Image 2 生成一张图片，只需三步：提交、查询状态、下载。

## 准备工作

- 已在 [Console](https://yir.ai/zh/console/billing) 充值的 Yir 账户。
- 从 [Console → API Keys](https://yir.ai/zh/console/api-keys) 获取的 API Key，见[身份认证](/zh/docs/getting-started/authentication)。
- 安装了 `curl` 和 `jq` 的终端。

```bash
export YIR_API_KEY="your-yir-api-key"
```

API Key 只能保存在服务端，不要放进浏览器或移动端代码。

## 1. 提交生成请求

```bash
curl https://gateway.yir.ai/v1/images/generations \
  --header "Authorization: Bearer $YIR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "openai/gpt-image-2",
    "input": { "type": "text", "prompt": "云海之上一座安静的天文台" },
    "parameters": { "resolution": "1K", "aspect_ratio": "1:1", "n": 1 }
  }' | tee job.json
```

Yir 返回 HTTP `202` 和一个 Job：

```json
{
  "id": "1234567890",
  "object": "job",
  "status": "queued",
  "model": "openai/gpt-image-2",
  "error": null,
  "created_at": 1790000000,
  "urls": { "get": "/v1/jobs/1234567890", "cancel": "/v1/jobs/1234567890/cancel" }
}
```

保存 `id`，之后只需要它。

```bash
export YIR_JOB_ID="$(jq -r '.id' job.json)"
```

:::info
`Idempotency-Key` 可选，本例省略了它，因此每次 POST 都会创建新 Job。提交超时时，请先在 [Console → 日志](https://yir.ai/zh/console/logs)中查找已提交的 Job 再决定是否重试：再次发出无键 POST 可能创建重复任务。生产代码应在首次 POST 前保存一个键，并与完整请求一起复用，见[幂等提交](/zh/docs/guides/production-integration#幂等提交)。
:::

## 2. 等待 Job 完成

轮询轻量状态接口，直到 Job 进入终态：

```bash
while true; do
  status="$(curl --silent https://gateway.yir.ai/v1/jobs/$YIR_JOB_ID/status \
    --header "Authorization: Bearer $YIR_API_KEY" | jq -r '.status')"
  echo "status: $status"
  case "$status" in
    succeeded|failed|cancelled) break ;;
    *) sleep 5 ;;
  esac
done
```

Job 依次经历 `queued` → `running` → `delivering` → `succeeded`。图片通常几十秒完成，视频可能需要数分钟。见 [Job 生命周期](/zh/docs/concepts/task-lifecycle)。

## 3. 下载结果

读取完整 Job 并下载文件：

```bash
curl --silent https://gateway.yir.ai/v1/jobs/$YIR_JOB_ID \
  --header "Authorization: Bearer $YIR_API_KEY" > job.json

jq '{status, error, charged: .billing.total_charged_by_yir, file: .result.files[0]}' job.json

curl --location --output image.png "$(jq -r '.result.files[0].url' job.json)"
```

结果地址是短期签名链接，不要向它发送 API Key。请把文件复制到自己的存储。结果自 Job 创建起保留 7 天，见[结果与保留期](/zh/docs/concepts/task-lifecycle#结果与保留期)。

如果 Job 为 `failed`，读取 `error.code` 与 `error.action`，并在[错误码](/zh/docs/support/error-codes)中查阅。失败的 Job 不收费。
