Yir 为长耗时图片与视频生成提供一套 Standard API 与 SDK 合同。应用只提交一次，保存 Yir Job ID，并持续查询同一个 Job 直到公开终态。

:::info
当前公开 HTTP 预览只包含已进入评审版 Standard OpenAPI 的操作。Provider 来源兼容路由不属于 Yir v1。
:::

## 单一公共任务合同

- 直接 HTTP 客户端调用 Yir Standard REST。
- Yir 原生 SDK 封装相同的 Standard 请求。
- Vercel AI SDK 客户端适配层把媒体调用转换为相同 Standard 请求，不增加第二套 Job、路由或计费合同。
