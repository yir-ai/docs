title: Vercel AI SDK
description: 通过官方适配器，在 Vercel AI SDK 中把 Yir 用作图片与视频 Provider。
---

`@yir-ai/sdk/vercel` 适配器让 [AI SDK](https://ai-sdk.dev) 的 `generateImage` 与实验性视频函数运行在 Yir 上。它发送的 Standard API 请求与原生 SDK 相同，因此 Job、路由和计费规则与本文档其他部分完全一致。

适配器面向 AI SDK 7（Provider V4），已用 `ai@7.0.97` 测试。请只在服务端使用。

```sh
pnpm add @yir-ai/sdk@0.2.1 ai@7.0.97
```

## 图片

```ts
import { generateImage } from "ai";
import { createYirAIProvider } from "@yir-ai/sdk/vercel";

const yir = createYirAIProvider(); // 读取 YIR_API_KEY

const { images } = await generateImage({
  model: yir.imageModel("openai/gpt-image-2"),
  prompt: "云海之上一座安静的天文台",
  aspectRatio: "1:1",
  maxRetries: 0,
  providerOptions: {
    yir: {
      idempotencyKey: "order-123-image-1",
      maxCost: "0.05",
      parameters: { resolution: "1K" },
    },
  },
});
```

图片路径会提交 Job、等待完成并下载结果。

## 视频

对于耗时较长的视频 Job，先启动并保存返回的 operation，之后再查询，甚至可以在另一个进程中查询：

```ts
import { experimental_startVideo as startVideo, experimental_getVideoStatus as getVideoStatus } from "ai";

const model = yir.videoModel("bytedance/seedance-2.0");

const { operation } = await startVideo({
  model,
  prompt: "一只纸船漂过被雨水覆盖的街道",
  maxRetries: 0,
  providerOptions: { yir: { idempotencyKey: "order-123-video-1", maxCost: "0.60" } },
});
// operation 为 { jobId, modelId }，可 JSON 序列化，请持久化保存。

const status = await getVideoStatus(model, { operation, maxRetries: 0 });
// status.status 为 "pending"、"completed" 或 "error"
```

也支持 `experimental_generateVideo`，它会一直等到视频完成。

## Provider 选项

Yir 特有选项放在 `providerOptions.yir` 中，未知字段会被拒绝。

| 选项 | 说明 |
| --- | --- |
| `idempotencyKey` | 推荐提供。省略时适配器为每次调用自动生成（新版本会打印警告），之后的调用无法用它恢复。请持久化并传入自己的键。 |
| `maxCost` | Job 的支出上限，十进制字符串。见[计费](/zh/docs/concepts/billing#设置支出上限)。 |
| `parameters` | Yir 模型参数，例如 `resolution`、`quality` 或 `web_search`。 |
| `routing` | Yir [路由](/zh/docs/concepts/routing)对象，`routing.only` 为无序白名单。 |

## AI SDK 字段映射

| AI SDK 字段 | Yir 请求 |
| --- | --- |
| `aspectRatio` | `parameters.aspect_ratio` |
| `n` | `parameters.n`（必须为 `1`） |
| 视频 `duration`、`generateAudio` | `parameters.duration`、`parameters.generate_audio` |
| `webhookUrl`（视频） | `webhook_url` |
| 提示词中的图片、`frameImages` | 图片参考、首帧与尾帧角色 |
| `inputReferences` | 按显式 MIME 类型映射为图片、视频或音频参考 |
| 内联字节 | 先通过 Files API 上传，再以文件 ID 引用 |

远程视频参考请传入 `{ data: "https://...", mediaType: "video/mp4" }`。同一参数若同时通过 AI SDK 字段和 `parameters` 设置且取值不同，调用会被拒绝。

以下能力不支持，会直接拒绝而不是静默忽略：图片 mask、像素 `size`、`seed`、视频像素 `resolution`、`fps` 以及单次调用的 headers。请用 Yir 的 `parameters.resolution` 代替像素尺寸。

## 注意事项

- 适配器不负责报价或预算审批。如需价格，请先用[原生客户端](/zh/docs/guides/clients)调用 `quoteImage` / `quoteVideo`。
- 请设置 `maxRetries: 0`，或始终传入已持久化的 `idempotencyKey`，避免 AI SDK 的重试创建额外 Job。
- 中止或超时只停止本地等待。要停止远端 Job，请调用原生 `cancelJob`；当前尝试仍可能成功并收费。
- 最终的 `parameter_notices` 会作为生成 `warnings` 返回，Job ID 与收费金额在 `providerMetadata.yir` 中。
