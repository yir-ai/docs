---
title: 图片生成
description: 使用 Yir Standard API 从文本或参考图生成图片。
---

图片 Job 提交到 `POST /v1/images/generations`。所有图片模型使用相同的请求结构，每个模型的合同决定可用的参数值和参考图数量。

## 请求字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `model` | 是 | 模型 ID，例如 `openai/gpt-image-2`。见[模型与参数](/zh/docs/guides/models)。 |
| `input` | 是 | `{ "type": "text", "prompt": ... }` 或 `{ "type": "image", "prompt": ..., "references": [...] }`。提示词 1–20,000 个字符。 |
| `parameters` | 是 | 模型参数，例如 `resolution`、`aspect_ratio`、`quality` 和 `n`。 |
| `max_cost` | 否 | 可选，整个 Job 的美元费用上限；估价超过它的渠道会被跳过，见[计费](/zh/docs/concepts/billing#设置支出上限)。 |
| `billing_mode` | 否 | 对支持的渠道显式选择 `actual`，成功交付的 winner 实际费用可形成钱包欠款。必须指定 `routing.only`，不能携带 `max_cost`，见[计费](/zh/docs/concepts/billing)。 |
| `routing` | 否 | 渠道偏好、白名单、版本与切换，见[路由](/zh/docs/concepts/routing)。 |
| `webhook_url` | 否 | 接收终态 Job 的 HTTPS 地址，见 [Webhook](/zh/docs/guides/webhooks)。 |

每个请求产出一个结果（`n` 固定为 `1`）。需要多张图片时，请提交多个 Job，每个 Job 使用独立的幂等键。

## 文生图

```json
{
  "model": "openai/gpt-image-2",
  "input": {
    "type": "text",
    "prompt": "松林里看地图的水彩小狐狸"
  },
  "parameters": { "resolution": "2K", "aspect_ratio": "3:2", "n": 1 }
}
```

## 图生图

把 `input.type` 设为 `image`，按顺序列出参考图。每张图片都必须先通过[输入文件 API](/zh/docs/guides/input-files)上传，等待分析状态为 `ready` 后，以 `reference_image` 角色和 `file_id` 引用。生成请求不接受外部 URL。

```json
{
  "model": "openai/gpt-image-2",
  "input": {
    "type": "image",
    "prompt": "把第一张图中的商品放到第二张图的桌子上",
    "references": [
      { "role": "reference_image", "file_id": "file_44444444-4444-4444-8444-444444444444" },
      { "role": "reference_image", "file_id": "file_11111111-1111-4111-8111-111111111111" }
    ]
  },
  "parameters": { "resolution": "1K", "aspect_ratio": "auto", "n": 1 }
}
```

请把示例文件 ID 替换为你自己的 ready 文件。参考图数量上限由模型合同决定，许多模型支持多张。

## 模型特有参数

参数会按所选模型校验，不被接受的值返回 `400 YIR_INVALID_REQUEST`。值得注意的参数：

| 参数 | 模型 | 说明 |
| --- | --- | --- |
| `quality` | GPT Image 等 | GPT Image 只有在路由允许的每条渠道都支持画质时才生效，见 [GPT Image 2](/zh/docs/models/gpt-image-2#画质) 与 [GPT Image 2.5](/zh/docs/models/gpt-image-2-5#画质)。 |
| `web_search` | Nano Banana 2、Nano Banana Pro | 默认 `false`，需要支持搜索的渠道，请以报价确认。 |
| `image_search` | Nano Banana 2 | 需要同时设置 `web_search: true`。 |

任意模型的完整参数可通过 `GET /v1/models/{creator}/{model}?view=contract` 查询。

## 提交与获取结果

1. 可选：用相同请求体（去掉 `max_cost` 和 `webhook_url`）调用 `POST /v1/images/quotes` 报价。
2. 携带必填的 `Idempotency-Key` Header 提交到 `POST /v1/images/generations`。
3. 轮询 `GET /v1/jobs/{id}/status`，或等待 Webhook。
4. 读取 `GET /v1/jobs/{id}`，下载 `result.files[].url`。每个文件带有 `media_type`，已知时还有 `width` 和 `height`。

[快速上手](/zh/docs/getting-started/quickstart)用 cURL 演示了完整步骤。
