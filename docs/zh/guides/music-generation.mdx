---
title: 音频生成
description: 使用 Yir Standard API 生成歌曲、纯音乐、音效和文字转语音。
---

音频 Job（音乐、音效与文字转语音）提交到 `POST /v1/audio/generations`，报价用 `POST /v1/audio/quotes`。`/v1/music/generations` 与 `/v1/music/quotes` 是这组接口的旧名，永久可用，行为完全相同。音频遵循与图片、视频相同的[生命周期](/zh/docs/concepts/task-lifecycle)、[计费](/zh/docs/concepts/billing)、[路由](/zh/docs/concepts/routing)和 [Webhook](/zh/docs/production/webhooks) 规则。每个 Job 返回模型单次请求生成的全部曲目：多数模型一首，Suno 两首。

## 请求字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `model` | 是 | 音乐、音效或文字转语音模型，例如 `minimax/music-2.6`。见[模型与参数](/zh/docs/models)。 |
| `input` | 是 | `{ "type": "text", "prompt": ..., "lyrics": ... }`。`prompt` 描述风格、情绪和使用场景，或描述声音。`lyrics` 各行用 `\n` 分隔。长度上限因模型而异。Suno 还接受 `reference` 输入，用于[上传原曲翻唱](#上传原曲翻唱)。 |
| `parameters` | 否 | 只接受模型合同声明的参数：`instrumental` 和 `lyrics_optimizer`（默认 `false`）、按时长计价模型的 `duration`，以及 `n`（`1`，Suno 为 `2`）。 |
| `max_cost` | 否 | 可选，Job 的美元费用上限，见[计费](/zh/docs/concepts/billing#设置支出上限)。 |
| `routing` | 否 | 见[路由](/zh/docs/concepts/routing)。 |
| `webhook_url` | 否 | 接收终态 Job 的 HTTPS 地址。 |

人声音乐必须提供 `lyrics`。设置 `lyrics_optimizer: true` 并省略 `lyrics`，模型会根据提示词自动写词；设置 `instrumental: true` 并省略两者，则生成不含人声的曲目。其他组合返回 `400 YIR_INVALID_REQUEST`。各模型支持的选项不同：

| 模型 | 歌词 | 时长 | 每个 Job 曲目数 |
| --- | --- | --- | --- |
| [MiniMax Music 2.6](/zh/docs/models/minimax/music-2-6) | 自带歌词、自动写词或纯音乐 | 由模型决定 | 1 |
| [MiniMax Music 3](/zh/docs/models/minimax/music-3) | 必须自带歌词 | 随歌词结束，最长 300 秒 | 1 |
| [ElevenLabs Music v2](/zh/docs/models/elevenlabs/music-v2) 与 [v2.5](/zh/docs/models/elevenlabs/music-v2-5) | 自动写词或纯音乐，不接收自带歌词 | `duration`：30–300 秒，默认 60 | 1 |
| [Suno v6](/zh/docs/models/suno/suno-v6)、[v6 Wild](/zh/docs/models/suno/suno-v6-wild) 与 [v6 Mini](/zh/docs/models/suno/suno-v6-mini) | 自带歌词、自动写词或纯音乐 | 由模型决定 | 2 |

Suno 没有官方 API，Yir 经第三方渠道非官方接入 Suno v6 系列。不支持控制速度或调性。价格与计费规则见各模型页。

## 上传原曲翻唱

Suno v6、v6 Wild 与 v6 Mini 可以翻唱你提供的歌曲：保留原曲旋律，按提示词描述的风格重新演绎。传 `input.type: "reference"`，并给出恰好一段 `reference_audio`（[Files API](/zh/docs/guides/input-files) 的 `file_id` 或公开 HTTPS `url`，不超过 8 分钟）。歌词规则与上文相同：传新的 `lyrics`、设置 `lyrics_optimizer: true` 或设置 `instrumental: true`。翻唱每次返回两首，价格与基础生成相同。其他音频模型的 reference 输入返回 `400 YIR_INVALID_REQUEST`。

```json
{
  "model": "suno/suno-v6",
  "input": {
    "type": "reference",
    "prompt": "Acoustic folk, fingerpicked guitar and a soft female vocal",
    "references": [{ "role": "reference_audio", "file_id": "file_..." }]
  },
  "parameters": { "lyrics_optimizer": true }
}
```

## 音效

[ElevenLabs Sound Effects v2](/zh/docs/models/elevenlabs/sound-effects-v2) 通过同一组接口生成短音效。只传 `input.prompt`（最多 450 个字符），可选 `parameters.duration`，为 1 到 22 的整数秒（默认 5）；传歌词、`instrumental` 或 `lyrics_optimizer` 会被拒绝。

```json
{
  "model": "elevenlabs/sound-effects-v2",
  "input": { "type": "text", "prompt": "A heavy wooden door creaking open in an empty stone hall" },
  "parameters": { "duration": 5 }
}
```

## 文字转语音

[MiniMax Speech 2.8 HD](/zh/docs/models/minimax/speech-2-8-hd)（最多 10000 字符）与 [ElevenLabs v3](/zh/docs/models/elevenlabs/eleven-v3)（最多 5000 字符）朗读 `input.prompt`。`parameters` 只接受 `n`（`1`）与 `voice`（模型的预设音色 ID，省略则用模型默认音色），音色不影响价格；传歌词、`instrumental`、`lyrics_optimizer` 或 `duration` 会被拒绝。文字转语音按提示词字符数计价，空格、标点与音频标签都计入，报价的 operation 为 `generate_speech`。Job 交付一个 MP3。

```json
{
  "model": "minimax/speech-2.8-hd",
  "input": { "type": "text", "prompt": "清晨六点，城市还没有完全醒来。" },
  "parameters": { "voice": "Chinese (Mandarin)_News_Anchor" }
}
```

## 报价、提交与获取结果

用相同的请求体（不含 `max_cost` 和 `webhook_url`）报价，并检查 `supply.available`：

```bash
curl https://gateway.yir.ai/v1/audio/quotes \
  --header "Authorization: Bearer $YIR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "minimax/music-2.6",
    "input": {
      "type": "text",
      "prompt": "温暖的独立民谣，木吉他与轻柔人声，清晨散步",
      "lyrics": "[Verse]\n晨光落在空荡的街\n[Chorus]\n陪我慢慢走一段"
    }
  }'
```

带上 `Idempotency-Key` 提交：

```bash
curl https://gateway.yir.ai/v1/audio/generations \
  --header "Authorization: Bearer $YIR_API_KEY" \
  --header "Content-Type: application/json" \
  --header "Idempotency-Key: audio-$(date +%s)" \
  --data '{
    "model": "minimax/music-2.6",
    "input": {
      "type": "text",
      "prompt": "温暖的独立民谣，木吉他与轻柔人声，清晨散步",
      "lyrics": "[Verse]\n晨光落在空荡的街\n[Chorus]\n陪我慢慢走一段"
    }
  }' | tee job.json

export YIR_JOB_ID="$(jq -r '.id' job.json)"
```

轮询到终态后下载曲目：

```bash
while true; do
  status="$(curl --silent https://gateway.yir.ai/v1/jobs/$YIR_JOB_ID/status \
    --header "Authorization: Bearer $YIR_API_KEY" | jq -r '.status')"
  echo "status: $status"
  case "$status" in
    succeeded|failed|cancelled) break ;;
    *) sleep 5 ;;
  esac
done

curl --silent https://gateway.yir.ai/v1/jobs/$YIR_JOB_ID \
  --header "Authorization: Bearer $YIR_API_KEY" > job.json
curl --location --output track.mp3 "$(jq -r '.result.files[0].url' job.json)"
```

## 结果

成功的 Job 在 `result.files` 中返回音频，每首曲目一个文件（Suno 为两个），各自带实测 `duration_ms`。多数模型（含文字转语音）交付 MP3（`media_type: "audio/mpeg"`），MiniMax Music 3 交付 WAV（`audio/wav`）。URL 是短期签名链接，请把文件复制到自己的存储。见[结果与保留期](/zh/docs/concepts/task-lifecycle#结果与保留期)。
