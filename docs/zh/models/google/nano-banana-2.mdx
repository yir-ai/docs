## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `resolution` | 分辨率：输出内容的分辨率。 | `0.5K`、`1K`、`2K`、`4K` | `1K` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 | `auto`、`21:9`、`16:9`、`3:2`、`4:3`、`5:4`、`1:1`、`4:5`、`3:4`、`2:3`、`9:16`、`4:1`、`1:4`、`8:1`、`1:8` | `auto` | 否 |
| `web_search` | 网页搜索：由支持的供应渠道执行网页搜索，可用性与费用以报价为准。 | `false`、`true` | `false` | 否 |
| `image_search` | 图片搜索：图片搜索必须同时启用 web_search；供应可用性与费用以报价为准。 | `false`、`true` | `false` | 否 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "google/nano-banana-2",
  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "auto",
    "web_search": false,
    "image_search": false,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "google/nano-banana-2",
  "input": {
    "type": "image",
    "prompt": "A watercolor fox reading a map in a pine forest",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "auto",
    "web_search": false,
    "image_search": false,
    "n": 1
  }
}
```
