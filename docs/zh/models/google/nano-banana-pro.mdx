## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `resolution` | 分辨率：输出内容的分辨率。 | `1K`、`2K`、`4K` | `1K` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 | `auto`、`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`、`21:9` | `auto` | 否 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "google/nano-banana-pro",
  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "auto",
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "google/nano-banana-pro",
  "input": {
    "type": "image",
    "prompt": "A watercolor fox reading a map in a pine forest",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "auto",
    "n": 1
  }
}
```
