## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `text` 纯文本 | — | — |
| `image` 图片输入 | 1–2 | `first_frame` 1<br />`last_frame` 0–1 |
| `reference` 参考素材 | 1–4 | `reference_image` |

## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `duration` | 时长：输出视频的秒数。 | `4`、`6`、`8`、`10` | `4` | 是 |
| `resolution` | 分辨率：输出内容的分辨率。 | `720p` | `720p` | 是 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 | `16:9`、`9:16` | `16:9` | 是 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 是 |

## 示例

`text` 输入：

```json
{
  "model": "google/gemini-omni-video",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 4,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "google/gemini-omni-video",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 4,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "n": 1
  }
}
```

`reference` 输入：

```json
{
  "model": "google/gemini-omni-video",
  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 4,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "n": 1
  }
}
```
