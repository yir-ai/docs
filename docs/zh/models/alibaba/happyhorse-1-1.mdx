## 示例

`text` 输入：

```json
{
  "model": "alibaba/happyhorse-1.1",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "alibaba/happyhorse-1.1",

    "type": "image",

      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "adaptive",

  }

```
