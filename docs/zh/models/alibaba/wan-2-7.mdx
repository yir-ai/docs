| `alibaba/wan-2.7` | `wan-2.7`、`wan2.7` | [视频生成](/zh/docs/guides/video-generation) |

## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `text` 纯文本 | — | — |
| `reference` 参考素材 | 1–5 | `reference_image` 0–5<br />`reference_video` 0–3<br />带 `reference_video` 时最长 10 秒 |

## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `duration` | 时长：输出视频的秒数。 | `2`–`15` | `5` | 是 |
| `resolution` | 分辨率：输出内容的分辨率。 | `720p`、`1080p` | `720p` | 是 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 | `16:9`、`9:16`、`1:1`、`4:3`、`3:4` | `16:9` | 是 |
| `generate_audio` | 生成音频：随视频生成原生音频。 | `true` | `true` | 是 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 是 |

## 示例

`text` 输入：

```json
{
  "model": "alibaba/wan-2.7",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true,
    "n": 1
  }
}
```

`reference` 输入：

```json
{
  "model": "alibaba/wan-2.7",
  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true,
    "n": 1
  }
}
```
