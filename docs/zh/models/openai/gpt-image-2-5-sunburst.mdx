## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `text` 纯文本 | — | — |
| `image` 图片输入 | 1–16 | `reference_image` |

## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `resolution` | 分辨率：输出内容的分辨率。 | `1K`、`2K`、`4K` | `1K` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 | `auto`、`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`5:4`、`4:5`、`16:9`、`9:16`、`2:1`、`1:2`、`3:1`、`1:3`、`21:9`、`9:21` | `auto` | 否 |
| `quality` | 质量：图片生成质量档位。 | `low`、`medium`、`high`、`xhigh`、`max` | 不设置 | 否 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "openai/gpt-image-2.5-sunburst",
  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "auto",
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "openai/gpt-image-2.5-sunburst",
  "input": {
    "type": "image",
    "prompt": "A watercolor fox reading a map in a pine forest",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "auto",
    "n": 1
  }
}
```
