## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `resolution` | 分辨率：输出内容的分辨率。 | `1K`、`2K`、`4K` | `1K` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 2K 时仅支持 1:1, 3:2, 2:3, 4:3, 3:4, 5:4, 4:5, 16:9, 9:16, 2:1, 1:2, 3:1, 1:3, 21:9, 9:21。 4K 时仅支持 1:1, 3:2, 2:3, 4:3, 3:4, 5:4, 4:5, 16:9, 9:16, 2:1, 1:2, 3:1, 1:3, 21:9, 9:21。 | `auto`、`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`5:4`、`4:5`、`16:9`、`9:16`、`2:1`、`1:2`、`3:1`、`1:3`、`21:9`、`9:21` | `auto` | 否 |
| `size` | 单帧尺寸：GIF 每帧的像素，默认 512x512。需要 output_format=gif；GIF 只有 1K 方形帧，aspect_ratio 只能是 1:1 或 auto；768x768 最多 12 帧。 | `512x512`、`768x768` | 不设置 | 否 |
| `output_format` | 输出格式：gif 输出动图，svg 输出矢量文件（1K 或 2K，需具体画幅，默认 1:1；只有一条渠道，写 SVG 的文本模型另计费）。gif 可带参考图，svg 只支持文生图；省略时输出静态图。 | `gif`、`svg` | 不设置 | 否 |
| `frame_count` | 帧数：GIF 帧数，默认 9。所有帧在同一张拼图上生成，2 到 8 帧同价。需要 output_format=gif。 | `2`–`16` | 不设置 | 否 |
| `frame_duration_ms` | 每帧时长：GIF 每帧的毫秒数，默认 200。需要 output_format=gif。 | `20`–`2000` | 不设置 | 否 |
| `quality` | 质量：图片生成质量档位。 | `low`、`medium`、`high`、`xhigh`、`max` | 不设置 | 否 |
| `n` | 单次请求输出数量：单次 API 请求（一个 Job）的输出数量，不是应用的批量张数。应用可提交多个独立请求组成一批；n=1 不表示应用只能生成一张。 | `1` | `1` | 否 |

```json
  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "auto",
    "n": 1
  }
}
```

```json
{
  "model": "openai/gpt-image-2.6-sunburst",
  "input": {
    "type": "image",
    "prompt": "A watercolor fox reading a map in a pine forest",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "auto",
    "n": 1
  }
}
```
