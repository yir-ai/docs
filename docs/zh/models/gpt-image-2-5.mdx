GPT Image 2.5 是 OpenAI 的图片生成与编辑模型，提供两个版本，各自使用独立的模型 ID：

| 模型 ID | 别名 | 版本 |
| --- | --- | --- |
| `openai/gpt-image-2.5-flare` | `gpt-image-2.5-flare` | 标准：日常生图与快速迭代 |
| `openai/gpt-image-2.5-sunburst` | `gpt-image-2.5-sunburst` | 精细：细节编辑与复杂视觉创作 |

两个版本都通过统一的[图片生成](/zh/docs/guides/image-generation)接口支持文生图和最多 16 张参考图的图片编辑。

## 示例

```json
{
  "model": "openai/gpt-image-2.5-flare",
  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": { "resolution": "2K", "aspect_ratio": "16:9", "n": 1 }
}
```

图片编辑时将 `input.type` 设为 `image`，并添加来自 [Files API](/zh/docs/guides/input-files) 的 `reference_image` 参考图。

## 参数

| 参数 | 取值 | 默认值 |
| --- | --- | --- |
| `resolution` | `1K`、`2K`、`4K` | `1K` |
| `aspect_ratio` | `auto`、`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`5:4`、`4:5`、`16:9`、`9:16`、`2:1`、`1:2`、`3:1`、`1:3`、`21:9`、`9:21` | `auto` |
| `quality` | `low`、`medium`、`high`、`xhigh`、`max` | 不设置，见[画质](#画质) |
| `n` | `1` | `1` |

完整列表以 `GET /v1/models/{creator}/{model}?view=contract` 为准。渠道可能只支持部分组合（例如部分渠道支持的画幅更少），请对完整请求[报价](/zh/docs/concepts/billing#获取报价)。

## 画质

`quality` 表示你需要的最低画质档位，并决定哪些渠道可以执行，规则与 [GPT Image 2](/zh/docs/models/gpt-image-2#画质) 相同：不传时所有渠道可执行、按 `medium` 估价；传入档位时只走承接该档位的渠道；不接受 `auto`。

| 渠道 | 可承接的档位 |
| --- | --- |
| 官方渠道（`openai`） | `low`、`medium`、`high`、`xhigh`、`max` |
| APIMart 标准版本 | `low`、`medium`、`high`、`xhigh`、`max` |
| APIMart `ext` 版本、KIE | `low`、`medium` |

APIMart `ext` 版本和 KIE 以不低于 `medium` 的固定画质出图，按张固定计价。`high` 及以上的请求只会走官方渠道或 APIMart 标准版本，这两条渠道会把档位发给上游。

```json
{
  "model": "openai/gpt-image-2.5-sunburst",
  "input": { "type": "text", "prompt": "A product photo of a ceramic mug" },
  "parameters": { "resolution": "1K", "aspect_ratio": "1:1", "quality": "high", "n": 1 }
}
```

需要最低价时不传 `quality`。模型详情的 `channel_parameters` 列出各渠道可承接的档位；在[模型市场](https://yir.ai/zh/models)选择画质档位时，不承接该档位的渠道会被标出。

## 与 OpenAI API 的差异

请求采用 Yir 的[通用请求格式](/zh/docs/models/official-api-differences)，按 OpenAI Images API 编写的代码需要做以下调整：

| OpenAI | Yir |
| --- | --- |
| `quality: "auto"`（OpenAI 默认值） | 不接受。改用 `low`、`medium`、`high`、`xhigh` 或 `max`，或省略 `quality`。见[画质](#画质)。 |
| `size`（像素尺寸或 `auto`） | `resolution` 加 `aspect_ratio`。 |
| `n` 大于 1 | `n` 固定为 `1`；每张图提交一个 Job。 |
| `background`、`output_format`、`output_compression`、`moderation` | 不可用。 |
| `stream`、`partial_images` | 不可用；结果在 Job 结束时返回。 |
| 局部重绘的 `mask` | 不可用；用 `reference_image` 参考图和提示词编辑。 |
| 图片 URL 或 base64 输入 | 传公开 HTTPS `url`，或通过 [Files API](/zh/docs/guides/input-files) 上传后传 `file_id`；不接受 base64。 |

## 计费

- 按 Token 计费的渠道（官方渠道与 APIMart 标准版本）返回仅含输出的估价：价格 `kind` 为 `estimate`，`estimate.scope` 为 `output_only`。估价按请求的档位计算，不传 `quality` 时按 `medium`。
- 按 Token 计费的渠道会把参考图另按图片输入 Token 计费。OpenAI 大致按 32×32 像素块计算输入图 Token，单张有上限；报价不包含这部分，因此使用多张大尺寸参考图编辑时，实际费用可能明显高于报价金额。
- APIMart `ext` 版本按输出分辨率每张固定计价，参考图不另收费。
- 最终费用为每次渠道计了费的尝试的上游实际费用 × 你的折扣之和，通常只有交付结果的那次，见[报价与计费](/zh/docs/concepts/billing)。
