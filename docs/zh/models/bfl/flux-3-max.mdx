## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `duration` | 时长：输出视频的秒数。 | `5`–`20` | `5` | 否 |
| `resolution` | 分辨率：输出内容的分辨率。 | `720p`、`1080p` | `720p` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `text` 模式。 | `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` | `16:9` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `image` 模式。 | `auto` | `auto` | 否 |
| `generate_audio` | 生成音频：随视频生成原生音频。 | `false`、`true` | `true` | 否 |
| `n` | 单次请求输出数量：单次 API 请求（一个 Job）的输出数量，不是应用的批量张数。应用可提交多个独立请求组成一批；n=1 不表示应用只能生成一张。 | `1` | `1` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "bfl/flux-3-max",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "bfl/flux-3-max",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "generate_audio": true,
    "n": 1
  }
}
```
