## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `text` 纯文本 | — | — |
| `image` 图片输入 | 1–8 | `reference_image` |

## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `resolution` | 分辨率：输出内容的分辨率。 | `1MP` | `1MP` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 | `1:1`、`4:3`、`3:4`、`16:9`、`9:16` | `1:1` | 否 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "bfl/flux-2-pro",
  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": {
    "resolution": "1MP",
    "aspect_ratio": "1:1",
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "bfl/flux-2-pro",
  "input": {
    "type": "image",
    "prompt": "A watercolor fox reading a map in a pine forest",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "resolution": "1MP",
    "aspect_ratio": "1:1",
    "n": 1
  }
}
```

完整合同以 `GET /v1/models/bfl/flux-2-pro?view=contract` 为准。参数合法不代表每个渠道都能执行，请对完整请求[报价](/zh/docs/concepts/billing#获取报价)。价格与渠道见[模型市场](https://yir.ai/zh/models)。
