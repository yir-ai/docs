## 示例

`text` 输入：

```json
{
  "model": "spacexai/grok-imagine-video-1.5",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 8,
    "resolution": "480p",
    "aspect_ratio": "16:9",
    "generate_audio": true,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "spacexai/grok-imagine-video-1.5",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 8,
    "resolution": "480p",
    "aspect_ratio": "auto",

    "n": 1
  }
}
```
