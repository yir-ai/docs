## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `duration` | 时长：输出视频的秒数。 | `1`–`30` | `5` | 否 |
| `resolution` | 分辨率：输出内容的分辨率。 | `720p`、`1080p` | `720p` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 | `auto` | `auto` | 否 |
| `seed` | 随机种子：可选随机种子；不同渠道使用相同种子不保证结果完全一致。 | `-9007199254740991`–`9007199254740991` | 不设置 | 否 |
| `generate_audio` | 生成音频：随视频生成原生音频。 | `true` | `true` | 否 |
| `n` | 单次请求输出数量：单次 API 请求（一个 Job）的输出数量，不是应用的批量张数。应用可提交多个独立请求组成一批；n=1 不表示应用只能生成一张。 | `1` | `1` | 否 |

## 示例

`reference` 输入：

```json
{
  "model": "pruna/p-video-replace",
  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      },
      {
        "role": "reference_video",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "generate_audio": true,
    "n": 1
  }
}
```

完整合同以 `GET /v1/models/pruna/p-video-replace?view=contract` 为准。参数合法不代表每个渠道都能执行，请对完整请求[报价](/zh/docs/concepts/billing#获取报价)。价格与渠道见[模型市场](https://yir.ai/zh/models)。
