## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `instrumental` | 纯音乐：生成无人声的纯音乐；不能同时传 input.lyrics 或 lyrics_optimizer。 | `false`、`true` | `false` | 否 |
| `lyrics_optimizer` | 自动写词：按提示词自动写词；不能同时传 input.lyrics，部分模型另收写词费用（以报价为准）。 | `false`、`true` | `false` | 否 |
| `n` | 单次请求输出数量：单次 API 请求（一个 Job）的输出数量，不是应用的批量张数。应用可提交多个独立请求组成一批；n=1 不表示应用只能生成一张。 | `2` | `2` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "suno/suno-v6",
  "input": {
    "type": "text",
    "prompt": "Warm indie folk, acoustic guitar and soft vocals, a quiet morning walk",
    "lyrics": "[Verse]\nMorning light on an empty street\n[Chorus]\nWalk with me, slow and sweet"
  },
  "parameters": {
    "instrumental": false,
    "lyrics_optimizer": false,
    "n": 2
  }
}
```

完整合同以 `GET /v1/models/suno/suno-v6?view=contract` 为准。参数合法不代表每个渠道都能执行，请对完整请求[报价](/zh/docs/concepts/billing#获取报价)。价格与渠道见[模型市场](https://yir.ai/zh/models)。
