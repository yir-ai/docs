## 示例

`text` 输入：

```json
{
  "model": "minimax/minimax-h3-image",
  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": {
    "resolution": "4K",
    "aspect_ratio": "1:1",
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "minimax/minimax-h3-image",
  "input": {
    "type": "image",
    "prompt": "A watercolor fox reading a map in a pine forest",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "resolution": "4K",
    "aspect_ratio": "1:1",
    "n": 1
  }
}
```
