## 示例

`text` 输入：

```json
{
  "model": "minimax/minimax-h3",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 6,
    "resolution": "768P",
    "aspect_ratio": "16:9",
    "generate_audio": true,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "minimax/minimax-h3",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 6,
    "resolution": "768P",
    "aspect_ratio": "adaptive",
    "generate_audio": true,
    "n": 1
  }
}
```

`reference` 输入：

```json
{
  "model": "minimax/minimax-h3",
  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 6,
    "resolution": "768P",
    "aspect_ratio": "adaptive",
    "generate_audio": true,
    "n": 1
  }
}
```
