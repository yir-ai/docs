## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `text` 纯文本 | — | — |
| `reference` 参考素材 | 1–7 | `reference_image` 0–7 |
| `image` 图片输入 | 1–2 | `first_frame` 1<br />`last_frame` 0–1 |

提示词上限：2500 个字符，超出时返回 400。

### 主体参考（`reference`）

给参考素材设置相同的 `references[].subject` 名称即可归为一个主体，提示词中用 `@<subject>` 引用。

- 照片主体：最多 7 个，每个 2–4 张 `reference_image`
- 主体可与未分组参考素材同时使用；参考数量按“未分组参考素材数 + 主体数”计，角色数量限制只计未分组参考素材。

## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `duration` | 时长：输出视频的秒数。 | `3`–`15` | `5` | 否 |
| `resolution` | 分辨率：输出内容的分辨率。 | `720p`、`1080p`、`4K` | `720p` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `text`、`reference` 模式。 | `16:9`、`9:16`、`1:1` | `16:9` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `image` 模式。 | `auto` | `auto` | 否 |
| `generate_audio` | 生成音频：随视频生成原生音频。 | `false`、`true` | `false` | 否 |
| `n` | 单次请求输出数量：单次 API 请求（一个 Job）的输出数量，不是应用的批量张数。应用可提交多个独立请求组成一批；n=1 不表示应用只能生成一张。 | `1` | `1` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "klingai/kling-3.0-omni",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": false,
    "n": 1
  }
}
```

`reference` 输入：

```json
{
  "model": "klingai/kling-3.0-omni",
  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": false,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "klingai/kling-3.0-omni",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "generate_audio": false,
    "n": 1
  }
}
```
