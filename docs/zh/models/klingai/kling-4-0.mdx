## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `text` 纯文本 | — | — |
| `image` 图片输入 | 1–10 | `first_frame` 1<br />`keyframe` 0–8<br />`last_frame` 0–1 |
| `reference` 参考素材 | 1–15 | `reference_audio` 仅用于主体<br />`reference_image` 0–10<br />`reference_video` 0–5 |

### 主体参考（`reference`）

给参考素材设置相同的 `references[].subject` 名称即可归为一个主体，提示词中用 `@<subject>` 引用。

- 照片主体：最多 7 个，每个 2–4 张 `reference_image`
- 视频主体：最多 3 个，每个 1 个 `reference_video`，不带照片
- 音色：每个主体可加 1 个 `reference_audio` 作为其音色；只有 `reference_audio` 的主体是独立音色，最多 3 个
- 主体可与未分组参考素材同时使用；参考数量按“未分组参考素材数 + 主体数”计，角色数量限制只计未分组参考素材。

| `resolution` | 分辨率：输出内容的分辨率。 | `720p`、`1080p` | `720p` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `text` 模式。 | `16:9`、`9:16`、`1:1`、`21:9` | `16:9` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `image` 模式。 | `auto` | `auto` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `reference` 模式。 | `auto`、`16:9`、`9:16`、`1:1`、`21:9` | `auto` | 否 |
| `generate_audio` | 生成音频：随视频生成原生音频。 | `true` | `true` | 否 |
| `n` | 单次请求输出数量：单次 API 请求（一个 Job）的输出数量，不是应用的批量张数。应用可提交多个独立请求组成一批；n=1 不表示应用只能生成一张。 | `1` | `1` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "klingai/kling-4.0",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "klingai/kling-4.0",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "generate_audio": true,
    "n": 1
  }
}
```

`reference` 输入：

```json

  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",

      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "generate_audio": true,
    "n": 1
  }
}
```
