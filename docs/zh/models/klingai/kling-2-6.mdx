## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `duration` | 时长：输出视频的秒数。 仅 `text` 模式。 | `5`、`10` | `5` | 否 |
| `duration` | 时长：输出视频的秒数。 仅 `reference` 模式。 | `3`–`30` | `5` | 否 |
| `resolution` | 分辨率：输出内容的分辨率。 | `720p`、`1080p` | `720p` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `text` 模式。 | `16:9`、`9:16`、`1:1` | `16:9` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `reference` 模式。 | `auto` | `auto` | 否 |
| `generate_audio` | 生成音频：随视频生成原生音频。 | `false` | `false` | 否 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "klingai/kling-2.6",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": false,
    "n": 1
  }
}
```

`reference` 输入：

```json
{
  "model": "klingai/kling-2.6",
  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "generate_audio": false,
    "n": 1
  }
}
```
