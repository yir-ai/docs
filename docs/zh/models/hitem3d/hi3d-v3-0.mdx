## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `image` 图片输入 | 1 | `reference_image` |
| `multiview` 多视角图片 | 2–4 | `back_view` 0–1<br />`front_view` 1<br />`left_view` 0–1<br />`right_view` 0–1 |

## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `texture` | 贴图：贴图档位：none 只出白模，standard 与 hd 带贴图（hd 为更高分辨率贴图，部分模型支持）。 | `none`、`standard` | `standard` | 否 |
| `pbr` | PBR 贴图：在基础颜色之外生成 PBR 贴图（金属度、粗糙度、法线），需要带贴图；部分模型另收费（以报价为准）。 | `false`、`true` | `true` | 否 |
| `face_limit` | 目标面数：网格目标面数，结果可能略有出入；省略即模型默认。部分模型自定义面数另收费（以报价为准）。 | `100000`–`5000000` | 不设置 | 否 |
| `topology` | 拓扑：网格面类型：triangle 三角面或 quad 四边面（部分模型支持四边面重拓扑）；glb 文件内仍以三角面存储。 | `triangle` | `triangle` | 否 |
| `n` | 单次请求输出数量：单次 API 请求（一个 Job）的输出数量，不是应用的批量张数。应用可提交多个独立请求组成一批；n=1 不表示应用只能生成一张。 | `1` | `1` | 否 |

## 示例

`image` 输入：

```json
{
  "model": "hitem3d/hi3d-v3.0",
  "input": {
    "type": "image",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "texture": "standard",
    "pbr": true,
    "topology": "triangle",
    "n": 1
  }
}
```

`multiview` 输入：

```json
{
  "model": "hitem3d/hi3d-v3.0",
  "input": {
    "type": "multiview",
    "references": [
      {
        "role": "front_view",
        "file_id": "file_..."
      },
      {
        "role": "back_view",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "texture": "standard",
    "pbr": true,
    "topology": "triangle",
    "n": 1
  }
}
```

完整合同以 `GET /v1/models/hitem3d/hi3d-v3.0?view=contract` 为准。参数合法不代表每个渠道都能执行，请对完整请求[报价](/zh/docs/concepts/billing#获取报价)。价格与渠道见[模型市场](https://yir.ai/zh/models)。
