## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `resolution` | 分辨率：输出内容的分辨率。 | `1K`、`2K` | `1K` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 | `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`2:3`、`3:2`、`21:9` | `1:1` | 否 |
| `size` | 精确尺寸：精确输出像素，仅选择明确支持的渠道；与分辨率档位或画幅冲突时拒绝。 | `1024x1024`、`1152x864`、`864x1152`、`1424x800`、`800x1424`、`1248x832`、`832x1248`、`1568x672`、`2048x2048`、`2368x1776`、`1776x2368`、`2816x1584`、`1584x2816`、`2496x1664`、`1664x2496`、`3136x1344` | 不设置 | 否 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 否 |

`text` 输入：

  "input": {

    "aspect_ratio": "1:1",
