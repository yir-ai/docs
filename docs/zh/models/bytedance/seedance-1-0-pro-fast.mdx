## 示例

`text` 输入：

```json
{
  "model": "bytedance/seedance-1.0-pro-fast",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": false,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "bytedance/seedance-1.0-pro-fast",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": false,
    "n": 1
  }
}
```
