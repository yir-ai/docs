## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `text` 纯文本 | — | — |
| `image` 图片输入 | 1–2 | `first_frame` 1<br />`last_frame` 0–1 |
| `reference` 参考素材 | 1–20 | `reference_audio` 0–5<br />`reference_image` 0–10<br />`reference_video` 0–5 |

提示词上限：20480 个字符，超出时返回 400。

## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |

| `duration` | 时长：输出视频的秒数。 仅 `text`、`image` 模式。 | `4`–`30` | `5` | 否 |
| `duration` | 时长：输出视频的秒数。带参考视频时可传 "auto"，编辑类任务时长跟随输入视频，aspect_ratio 须同为 auto。task_type 为 edit 时即为 auto。 仅 `reference` 模式。 | `4`–`30`、`auto` | `5` | 否 |
| `resolution` | 分辨率：输出内容的分辨率。 | `480p`、`720p` | `720p` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `text`、`reference` 模式。 | `auto`、`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` | `auto` | 否 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `image` 模式。 | `auto` | `auto` | 否 |
| `return_last_frame` | 返回尾帧：由支持的供应渠道返回视频最后一帧图片。 | `false`、`true` | `false` | 否 |

## 示例

`text` 输入：

```json
{
  "model": "bytedance/seedance-2.5-flash",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "return_last_frame": false,
    "generate_audio": true,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "bytedance/seedance-2.5-flash",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "return_last_frame": false,
    "generate_audio": true,
    "n": 1
  }
}
```

`reference` 输入：

```json
{
  "model": "bytedance/seedance-2.5-flash",
  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "return_last_frame": false,
    "generate_audio": true,
    "n": 1,
    "task_type": "auto"
  }
}
```
