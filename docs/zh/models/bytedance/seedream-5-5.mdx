## 示例

`text` 输入：

```json
{

  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "bytedance/seedream-5.5",
  "input": {
    "type": "image",
    "prompt": "A watercolor fox reading a map in a pine forest",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "resolution": "1K",
    "aspect_ratio": "1:1",
    "n": 1
  }
}
```

`layer_decomposition` 输入：

```json
{
  "model": "bytedance/seedream-5.5",
  "input": {
    "type": "layer_decomposition",
    "references": [

        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "resolution": "auto",
    "max_images": 30
  }
}
```
