## 输入模式

| 模式 | 参考数量 | 参考角色 |
| --- | --- | --- |
| `text` 纯文本 | — | — |
| `reference` 参考素材 | 1–50 | `reference_image` 0–30<br />`reference_video` 0–10<br />至少包含 `reference_image`、`reference_video` 之一 |
| `image` 图片输入 | 1–2 | `first_frame` 1<br />`last_frame` 0–1 |

## 参数

| 参数 | 说明 | 取值 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| `duration` | 时长：输出视频的秒数。 | `4`–`30` | `4` | 是 |
| `resolution` | 分辨率：输出内容的分辨率。 | `480p`、`720p` | `720p` | 是 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `text`、`reference` 模式。 | `auto`、`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` | `16:9` | 是 |
| `aspect_ratio` | 画幅：输出内容的宽高比。 仅 `image` 模式。 | `auto` | `auto` | 是 |
| `generate_audio` | 生成音频：随视频生成原生音频。 | `false`、`true` | `false` | 是 |
| `n` | 输出数量：本次生成的内容数量。 | `1` | `1` | 是 |

## 示例

`text` 输入：

```json
{
  "model": "bytedance/seedance-2.5",
  "input": {
    "type": "text",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot"
  },
  "parameters": {
    "duration": 4,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": false,
    "n": 1
  }
}
```

`reference` 输入：

```json
{
  "model": "bytedance/seedance-2.5",
  "input": {
    "type": "reference",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "reference_image",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 4,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": false,
    "n": 1
  }
}
```

`image` 输入：

```json
{
  "model": "bytedance/seedance-2.5",
  "input": {
    "type": "image",
    "prompt": "A paper boat drifting down a rainy city street, slow tracking shot",
    "references": [
      {
        "role": "first_frame",
        "file_id": "file_..."
      }
    ]
  },
  "parameters": {
    "duration": 4,
    "resolution": "720p",
    "aspect_ratio": "auto",
    "generate_audio": false,
    "n": 1
  }
}
```
