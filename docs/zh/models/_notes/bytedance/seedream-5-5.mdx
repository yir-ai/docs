### 各渠道的提示词长度

文生图和图片编辑的 `input.prompt` 须包含 3–5000 个 Unicode 字符，按去除首尾空白后的长度计算。经 Yir 调用 APIMart 和 fal 时接受 3–5000 个字符，KIE 需要 5–5000 个字符。

提示词超出可选渠道的允许范围时，报价返回 HTTP 400 和 `YIR_INVALID_REQUEST`。`error.details[].field` 为 `input.prompt`，`expected` 给出允许范围。例如 `routing.only` 仅选 KIE 时，3–4 个字符的提示词会收到该错误。

fal 的基础价格按输出分辨率计。图片编辑对每张参考图另收费用，第一张也计费。按完整请求报价可查看当前金额。

### 图层拆分

在图片生成端点将 `input.type` 设为 `"layer_decomposition"`，传入一张参考图，提示词可省略。`parameters.resolution` 选择输出档位，`parameters.max_images` 控制最多返回多少个文件，含底图，默认 30。

从 `result.files` 读取文件。底图的 `layer.z_index` 为 0。按 `z_index` 从小到大叠放 PNG 图层，用 `bounding_box.absolute` 把每个图层缩放并定位到底图。坐标格式是 `[left, top, right, bottom]`。合成到其他尺寸的画布时可用 `bounding_box.normalized`。上游可能省略坐标。

APIMart 和 KIE 均支持这个输入模式。报价按输出上限加一张输入图估算，最终按渠道返回的任务实扣结算。
