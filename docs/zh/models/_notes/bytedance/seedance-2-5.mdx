## 任务类型

`reference` 模式下，`parameters.task_type` 告诉模型如何使用参考素材，对应字节官方的 `omni_reference_task_type`：

| 取值 | 用途 | 约束 |
| --- | --- | --- |
| `auto`（默认） | 模型根据素材和提示词自行判断。 | 提交时不校验；判断结果与参数冲突时，任务提交后才失败。 |
| `reference` | 参照图片、视频、音频生成新视频。 | `duration` 与 `aspect_ratio` 照常取固定值。 |
| `edit` | 修改参考视频，例如替换其中的主体。 | 需要 4–30 秒的 `reference_video`；`duration` 与 `aspect_ratio` 跟随原视频（省略或传 `"auto"`）。走 APIMart 和 KIE 渠道。 |
| `extend` | 延长参考视频。 | 需要 `reference_video`；`aspect_ratio` 跟随原视频，`duration` 为新增部分的秒数。走 APIMart 和 KIE 渠道。 |

模型仍会读提示词。读起来像编辑的提示词（如 "replace the dog in @video1"、"copy @video1 exactly"）在 `reference` 下可能被拒，或保留原视频里的主体。想保留动作、换掉主体时，描述动作并说明主体来自哪里（如 "the dog from @image1 trots down the stairs like the dog in @video1"），或改用 `edit`。

## 时长跟随参考视频

视频编辑时，使用 `input.type: "reference"`，至少提供一个 `reference_video`，并设置 `parameters.duration: "auto"`。将 `aspect_ratio` 设为 `"auto"` 或省略；自动时长不接受固定画幅。上游模型根据提示词判断请求是否属于编辑。纯文本、首帧和仅含图片的参考输入不能使用此选项。

Quote 接受公开 HTTPS 参考视频 URL，但不会下载素材。设置 `duration: "auto"` 且任一参考视频为 URL 时，供给可以可用，同时 `primary.amount` 和 `official.amount` 为 `null`，不返回 `expected_amount`。需要基于实测时长的估价时，请先上传视频并使用已就绪的 `file_id`。Submit 仍会先导入、校验并测量 URL 素材，再进行准入；未知估价不会绕过显式 `max_cost` 或其他预算限制。Quote 和 Job（包括 Webhook）均回显 `parameters.duration: "auto"`，不会替换成内部实测秒数；数值请求仍回显数值。

估价和准入按最长实测参考视频时长向上取整为秒，并限制在模型的 4–30 秒范围内。最终费用按实际上游金额结算，估价秒数不保证输出时长。

省略 `duration` 仍使用默认 4 秒；显式整数时长保持既有行为。不要向 Yir 传入上游的 `-1` 值。

文生视频新增 `parameters.resolution: "1080p"`，仅通过官方渠道执行；省略时仍为 `720p`，图片与参考模式仍只支持 `480p`/`720p`。官方 1080p 无视频输入费率为每百万视频 token 11.70 美元；16:9、24 fps、4 秒的输出估价为 2.27448 美元，最终按任务实际费用结算。该文生路线同时支持精确尺寸 `parameters.size: "1920x1080"`（AI SDK 的 `resolution: "1920x1080"`），绑定 1080p、16:9；与此冲突的画幅／档位及其他像素尺寸会明确拒绝。
