## 歌词

Music 3 用你自己的歌词生成带人声歌曲：`input.lyrics` 必填（最多 3,500 个字符，各行用 `\n` 分隔，可使用 `[Verse]`、`[Chorus]` 等结构标签），提示词最多 2,000 个字符。不支持 `instrumental` 和 `lyrics_optimizer`。

## 时长与输出

没有时长参数。歌曲随歌词结束，最长 300 秒。每个 Job 在 `result.files` 中返回一个 WAV 文件（`media_type: "audio/wav"`），`duration_ms` 为实测时长。

## 价格

通过 FAL 执行，每输出秒 0.002 美元。报价按 300 秒上限估算为 0.60 美元；最终费用按渠道对实际交付时长的计费金额结算，例如 2 分钟的歌曲约 0.24 美元。MiniMax 官方 Music-3.0 API 刊例价为每首 0.15 美元，但已不对新用户开放。
