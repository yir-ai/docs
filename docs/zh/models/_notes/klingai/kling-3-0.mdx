动作参考按参考视频实测时长计价，按渠道规则取整到整秒（APIMart 向下取整，KIE 向上取整，fal 四舍五入）；上传参考视频并传入其 `file_id`，报价才有金额。

Kling 动作参考可能因复杂或快速动作、切镜而生成比参考视频更短的结果，已消耗费用不保证退还，具体以渠道计费规则为准。

通过 fal 或 Higgsfield 生成首帧或首尾帧视频时，输出画幅跟随首帧，指定的 `aspect_ratio` 会被忽略。Quote 的 `parameter_notices` 提示预计处理方式；Job 的通知说明实际使用渠道的处理方式。文生视频仍使用指定画幅。

## 提示词长度

文生视频、首帧及首尾帧图生视频最多接受去除首尾空白后的 2500 个 Unicode 字符。超出上限会在提交前拒绝，Yir 不自动截断。主体参考与动作控制遵循各自合同。
