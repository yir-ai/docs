Yir provides one Standard API and SDK contract for long-running image and video generation. Submit once, persist the Yir Job ID, and query the same Job until it reaches a public terminal state.

:::info
The current published HTTP preview exposes only operations present in the reviewed Standard OpenAPI. Provider-specific source-compatible routes are not part of Yir v1.
:::

## One public task contract

- Direct HTTP clients call Yir Standard REST.
- Native Yir SDKs wrap the same Standard requests.
- The Vercel AI SDK adapter converts media calls into the same Standard requests; it does not introduce a second Job, routing, or billing contract.
