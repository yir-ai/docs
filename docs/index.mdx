Generate images and videos with one Standard API request. Yir picks a provider channel, falls back to another if an attempt fails (within your `max_cost`, when set), and tracks everything in one Job until the result is delivered.

## What a request looks like

```bash
curl https://gateway.yir.ai/v1/images/generations   --header "Authorization: Bearer $YIR_API_KEY"   --header "Content-Type: application/json"   --header "Idempotency-Key: my-first-job"   --data '{
    "model": "openai/gpt-image-2",
    "input": { "type": "text", "prompt": "A quiet observatory above a sea of clouds" },
    "parameters": { "resolution": "1K", "aspect_ratio": "1:1", "n": 1 }
  }'
```

Yir answers right away with `202` and a `queued` Job. Get the result from a Webhook or `GET /v1/jobs/{id}`. See the [quickstart](/docs/getting-started/quickstart) for every step.

## How a request flows

```mermaid
sequenceDiagram
  participant App as Your backend
  participant Yir as Yir Gateway
  participant P as Provider channels
  App->>Yir: POST /v1/images/quotes (optional)
  Yir-->>App: Price estimate
  App->>Yir: POST /v1/images/generations
  Yir-->>App: 202 Job (queued)
  Yir->>P: Attempt, then fallback if it fails
  P-->>Yir: Result
  Yir->>Yir: Copy result to Yir storage
  Yir-->>App: Webhook, or GET /v1/jobs/{id}
```

- **One Job per request.** Fallback attempts happen inside the Job. You never resubmit to recover from a provider failure.
- **Pay the channel's actual bill.** Every attempt the channel billed is charged after your discount, even if it failed; attempts the channel never billed cost nothing, and Yir absorbs its own delivery failures and timeouts. See [quotes and billing](/docs/concepts/billing).
- **No provider credentials.** Authenticate with your Yir API Key only. See [authentication](/docs/getting-started/authentication).
