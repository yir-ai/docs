The official `yir` skill lets coding agents such as Claude Code and Codex generate images, edit local images, and generate videos through Yir. It lists models and prices, quotes a request, submits the Job, waits for the result, and saves the files locally. The skill is open source in [yir-ai/skills](https://github.com/yir-ai/skills).

It needs Node.js 18 or later; the bundled script has no dependencies.

## Install

In Claude Code, install it as a plugin; updates arrive with `/plugin marketplace update yir-ai`:

```sh
/plugin marketplace add yir-ai/skills
/plugin install yir@yir-ai
```

Or copy `skills/yir` into your agent's skills directory. The script examples below use this copied location.

<CodeGroup>

```sh Claude Code
git clone https://github.com/yir-ai/skills.git
cp -r skills/skills/yir ~/.claude/skills/yir
```

```sh Codex
git clone https://github.com/yir-ai/skills.git
cp -r skills/skills/yir ~/.codex/skills/yir
```

</CodeGroup>

For Claude Code you can also use `.claude/skills/` inside a project. Other agents that support `SKILL.md` skills can point at the same folder.

## Set your API Key

Create an API Key in the Yir Console, then set it in the environment your agent runs in. See [authentication](/docs/getting-started/authentication).

```sh
export YIR_API_KEY="..."
```

Jobs are billed to your Yir wallet.

## Use

Ask your agent in plain language:

- "Generate a 16:9 hero image of a lighthouse at dusk with Yir."
- "Make a 5-second video from ./first-frame.png with Yir."

You can also run the script directly from where you installed it (shown here for Claude Code):

```sh
# Text to image
node ~/.claude/skills/yir/scripts/yir.mjs image -m openai/gpt-image-2 --prompt "a lighthouse at dusk" -p aspect_ratio=16:9

# Text to video
node ~/.claude/skills/yir/scripts/yir.mjs video -m bytedance/seedance-1.5-pro --prompt "waves at night" -p duration=4
```

Results are saved to `./yir-output` by default. Each result gets a `.json` sidecar with its prompt, parameters, channel, Job ID, and charge. Run `node ~/.claude/skills/yir/scripts/yir.mjs --help` for all commands, including `models`, `quote`, and `job <id> --wait --download`.

## Generate many assets at once

For a landing page, deck, or article, ask the agent for the whole set ("the hero, three feature images and a 5-second demo clip, under $2"). The skill writes a plan file and runs it as one batch:

```sh
# Check every job and quote the total; submits nothing
node ~/.claude/skills/yir/scripts/yir.mjs batch plan.json --dry-run --out ./assets

# Run with a spending limit
node ~/.claude/skills/yir/scripts/yir.mjs batch plan.json --max-total 2.00 --out ./assets
```

Before each submit the skill checks what earlier jobs actually charged against `--max-total`. Running the same command again resumes the batch: finished jobs are skipped and submitted jobs are not created twice. The plan format is in the skill's [SKILL.md](https://github.com/yir-ai/skills/blob/main/skills/yir/SKILL.md).
