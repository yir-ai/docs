## Source video and billing

Use `input.type: "reference"` with one 4–30 second MP4 as `reference_video` and 1–10 `reference_image` inputs. In your prompt, use `@video_1` and `@image_1` to identify the source and replacement.

Yir uses NanoAPI for this model at 720p or 1080p. For a numeric quote, upload the source through [Files](/docs/guides/input-files). Estimates round up the longer measured audio or video track to whole seconds. Final billing uses the channel's actual task charge.

Higgsfield's own Genjutsu Light API processes the first 15 seconds and bills output seconds. NanoAPI accepts 4–30 second inputs and bills source seconds.
