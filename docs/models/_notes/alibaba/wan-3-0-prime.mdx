### Prompt length by channel

Text and image prompts are limited to 5,000 characters. In `reference` mode, prompts from 5,001 to 8,000 characters are eligible only for NanoAPI. Its limit applies after Yir converts reference markers such as `@image_1` to the channel's syntax. Quote the exact request to check available supply.

The combined reference-video duration plus output duration must not exceed 30 seconds. Quotes and submissions validate this limit for measured uploaded `file_id` inputs and reject excess duration even without `max_cost`. A URL quote does not measure the video, so unknown duration does not confirm validity; use an uploaded, measured file to validate the duration before submission.
