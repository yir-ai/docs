Send one portrait as `reference_image` and the English words to speak as `input.prompt`. The model uses the fixed Zephyr voice and returns a speaking MP4 in the 720p tier. The model determines the exact dimensions and duration.

The listed rate is $0.025 per output second. The API settles the task after rendering using the upstream charge for that task. Leave out `duration` and `generate_audio`. The final total is unavailable before rendering, so requests with `max_cost` are unavailable on this route.
