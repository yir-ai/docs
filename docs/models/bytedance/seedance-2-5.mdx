| `task_type` | Task type: How the references are used. auto (default) lets the model decide from the references and prompt. reference generates a new video guided by them. edit changes the reference video (4 to 30 seconds); its duration and aspect ratio follow that video. extend continues the reference video; aspect_ratio follows it and duration is the length of the new part. The model still checks the prompt, so a prompt that reads as an edit (for example "replace" or "copy exactly") can fail as reference; edit and extend run on fewer channels.
