GPT Image 2.5 is OpenAI's image generation and editing model, available in two versions with separate model IDs:

| Model ID | Alias | Version |
| --- | --- | --- |
| `openai/gpt-image-2.5-flare` | `gpt-image-2.5-flare` | Standard: everyday generation and fast iteration |
| `openai/gpt-image-2.5-sunburst` | `gpt-image-2.5-sunburst` | Precise: detailed editing and complex visual work |

Both support text-to-image and image editing with up to 16 reference images through the standard [image generation](/docs/guides/image-generation) endpoint.

## Example

```json
{
  "model": "openai/gpt-image-2.5-flare",
  "input": {
    "type": "text",
    "prompt": "A watercolor fox reading a map in a pine forest"
  },
  "parameters": { "resolution": "2K", "aspect_ratio": "16:9", "n": 1 }
}
```

For image editing, set `input.type` to `image` and add `reference_image` references from the [Files API](/docs/guides/input-files).

## Parameters

| Parameter | Values | Default |
| --- | --- | --- |
| `resolution` | `1K`, `2K`, `4K` | `1K` |
| `aspect_ratio` | `auto`, `1:1`, `3:2`, `2:3`, `4:3`, `3:4`, `5:4`, `4:5`, `16:9`, `9:16`, `2:1`, `1:2`, `3:1`, `1:3`, `21:9`, `9:21` | `auto` |
| `quality` | `low`, `medium`, `high`, `xhigh`, `max` | Not set. See [quality](#quality) |
| `n` | `1` | `1` |

The authoritative list comes from `GET /v1/models/{creator}/{model}?view=contract`. Channels may support only some combinations (for example, some channels offer fewer aspect ratios), so [quote](/docs/concepts/billing#get-a-quote) the complete request.

## Quality

`quality` is the minimum quality tier you need, and it decides which channels can run the request. It works the same way as for [GPT Image 2](/docs/models/gpt-image-2#quality): omitted means every channel may run and the estimate assumes `medium`; a set tier routes only to channels that serve it; `auto` is not accepted.

| Channel | Tiers served |
| --- | --- |
| Official (`openai`) | `low`, `medium`, `high`, `xhigh`, `max` |
| APIMart standard version | `low`, `medium`, `high`, `xhigh`, `max` |
| APIMart `ext` version, KIE | `low`, `medium` |

APIMart's `ext` version and KIE render at a fixed quality of at least `medium` and charge a fixed price per image. Requests for `high` or above run on the official channel or APIMart's standard version, which send the tier upstream.

```json
{
  "model": "openai/gpt-image-2.5-sunburst",
  "input": { "type": "text", "prompt": "A product photo of a ceramic mug" },
  "parameters": { "resolution": "1K", "aspect_ratio": "1:1", "quality": "high", "n": 1 }
}
```

To get the lowest price, omit `quality`. Model detail lists each channel's tiers in `channel_parameters`, and [Model Market](https://yir.ai/models) marks the channels that do not serve the tier you select.

## Differences from the OpenAI API

Requests use Yir's [common request shape](/docs/models/official-api-differences), so code written for the OpenAI Images API needs these changes:

| OpenAI | Yir |
| --- | --- |
| `quality: "auto"` (OpenAI's default) | Not accepted. Use `low`, `medium`, `high`, `xhigh` or `max`, or omit `quality`. See [quality](#quality). |
| `size` (pixel sizes or `auto`) | `resolution` plus `aspect_ratio`. |
| `n` greater than 1 | `n` is always `1`; submit one Job per image. |
| `background`, `output_format`, `output_compression`, `moderation` | Not available. |
| `stream`, `partial_images` | Not available; the result arrives when the Job finishes. |
| `mask` for inpainting | Not available; edit with `reference_image` references and the prompt. |
| Image URLs or base64 inputs | Pass a public HTTPS `url`, or upload with the [Files API](/docs/guides/input-files) and pass `file_id`. Base64 is not accepted. |

## Billing

- Token-billed channels (official and APIMart's standard version) return an output-only estimate: the price `kind` is `estimate` and `estimate.scope` is `output_only`. The estimate uses the requested tier, or `medium` when `quality` is omitted.
- Reference images on token-billed channels are billed separately as image input tokens. OpenAI counts input image tokens roughly by 32×32-pixel patches, with a per-image cap; the quote does not include them, so editing with several large references can cost noticeably more than the quoted amount.
- APIMart's `ext` version charges a fixed price per output image by resolution, with no extra charge for references.
- The final charge is the sum of every channel-billed attempt's actual upstream cost × your discount, usually just the delivering attempt. See [quotes and billing](/docs/concepts/billing).
