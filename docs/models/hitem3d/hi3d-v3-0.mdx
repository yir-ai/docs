## Input modes

| Mode | References | Reference roles |
| --- | --- | --- |
| `image` Image input | 1 | `reference_image` |
| `multiview` Multi-view images | 2 to 4 | `back_view` 0 to 1<br />`front_view` 1<br />`left_view` 0 to 1<br />`right_view` 0 to 1 |

## Parameters

| Parameter | Description | Values | Default | Required |
| --- | --- | --- | --- | --- |
| `texture` | Texture: Texture tier: none returns an untextured mesh, standard and hd bake textures (hd is higher resolution where supported). | `none`, `standard` | `standard` | No |
| `pbr` | PBR: Generate PBR maps (metallic, roughness, normal) in addition to base color; requires a texture. Some models charge extra (see the quote). | `false`, `true` | `true` | No |
| `face_limit` | Target faces: Target polygon count of the mesh; the result can differ slightly. Omit to use the model default. Some models charge extra for a custom count (see the quote). | `100000` to `5000000` | Not set | No |
| `topology` | Topology: Mesh face type: triangle or quad (quad-dominant remesh where supported). The glb file stores triangles. | `triangle` | `triangle` | No |
| `n` | Outputs per request: Number of outputs from one API request (one Job), not the application batch size. For multiple Jobs, submit separate requests; n=1 does not prevent application-managed batching. | `1` | `1` | No |
