## Parameters

| Parameter | Description | Values | Default | Required |
| --- | --- | --- | --- | --- |
| `texture` | Texture: Texture tier: none returns an untextured mesh, standard and hd bake textures (hd is higher resolution where supported). | `none`, `standard` | `standard` | No |
| `pbr` | PBR: Generate PBR maps (metallic, roughness, normal) in addition to base color; requires a texture. Some models charge extra (see the quote). | `false`, `true` | `false` | No |
| `face_limit` | Target faces: Target polygon count of the mesh; the result can differ slightly. Omit to use the model default. Some models charge extra for a custom count (see the quote). | `100` to `300000` | `30000` | No |
| `topology` | Topology: Mesh face type: triangle or quad (quad-dominant remesh where supported). The glb file stores triangles. | `triangle`, `quad` | `triangle` | No |
| `n` | Outputs per request: Number of outputs from one API request (one Job), not the application batch size. For multiple Jobs, submit separate requests; n=1 does not prevent application-managed batching. | `1` | `1` | No |
