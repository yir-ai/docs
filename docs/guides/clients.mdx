The official SDKs are open source in [yir-ai/sdk](https://github.com/yir-ai/sdk) and cover quotes, generation, Job waiting, cancellation, file uploads, and Webhook verification. You can also call the REST API directly; the [quickstart](/docs/getting-started/quickstart) uses cURL.

| Language | Package | Current version |
| --- | --- | --- |
| TypeScript | `@yir-ai/sdk` | `0.3.0` |
| Go | `github.com/yir-ai/sdk/go` | `v0.4.0` |

Both clients read `YIR_API_KEY` from your server and default to `https://gateway.yir.ai`. Keep them on the server; the browser entry points of the TypeScript package contain only pure helpers and types.

## Install

<CodeGroup>

```sh TypeScript
pnpm add @yir-ai/sdk@0.3.0
```

```sh Go
go get github.com/yir-ai/sdk/go@v0.4.0
```

</CodeGroup>

The TypeScript package is ESM and needs a runtime with native `fetch`, Web Crypto, and `Blob` (Node.js 22 or later). The Go module requires Go 1.25 or later.

## Generate an image end to end

<CodeGroup>

```ts TypeScript
import { createNodeYirClient } from "@yir-ai/sdk/server";
import type { StandardImageGenerationRequest } from "@yir-ai/sdk/shared";

const client = createNodeYirClient(); // reads YIR_API_KEY

const request: StandardImageGenerationRequest = {
  model: "openai/gpt-image-2",
  input: { type: "text", prompt: "A quiet observatory above a sea of clouds" },
  parameters: { resolution: "1K", aspect_ratio: "1:1", n: 1 },
};

const quote = await client.quoteImage(request);
const ceiling = quote.single_attempt_upper_bound;
if (!quote.supply.available || !quote.has_verifiable_upper_bound || ceiling === null) {
  throw new Error("No bounded supply for this request");
}

// Persist the request, max_cost, and key before submitting so you can recover.
const saved = { request: { ...request, max_cost: ceiling }, idempotencyKey: crypto.randomUUID() };

const job = await client.submitImage(saved.request, saved.idempotencyKey);
const done = await client.waitForJob(job.id, { timeoutMs: 5 * 60_000 });

console.log(done.status, done.billing?.total_charged_by_yir);
if (done.result?.availability === "available") {
  console.log(done.result.files[0].url); // copy to your own storage
}
```

```go Go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Minute)
defer cancel()

client, err := yir.NewClient(os.Getenv("YIR_API_KEY"), yir.ClientOptions{})
if err != nil {
	return err
}

request := yir.GenerationRequest{
	Model:      "openai/gpt-image-2",
	Input:      yir.GenerationInput{Type: "text", Prompt: "A quiet observatory above a sea of clouds"},
	Parameters: map[string]any{"resolution": "1K", "aspect_ratio": "1:1", "n": 1},
}

quote, err := client.QuoteImage(ctx, request)
if err != nil {
	return err
}
if !quote.Supply.Available || !quote.HasVerifiableUpperBound || quote.SingleAttemptUpperBound == nil {
	return errors.New("no bounded supply for this request")
}

// Persist the request, MaxCost, and key before submitting so you can recover.
saved := yir.SubmitRequest{GenerationRequest: request, MaxCost: quote.SingleAttemptUpperBound}
key := "order-123-image-1"

job, err := client.SubmitImage(ctx, saved, key)
if err != nil {
	return err // An unknown outcome is not a failure: retry with the same saved request and key.
}

final, err := client.WaitJob(ctx, job.ID, yir.WaitOptions{})
var failed *yir.JobError
if errors.As(err, &failed) {
	return fmt.Errorf("job %s ended %s", failed.Job.ID, failed.Job.Status)
}
if err != nil {
	return err // Local timeout: the Job keeps running. Resume with job.ID later.
}
fmt.Println(final.Status, final.Billing.TotalChargedByYir, final.Result.Files[0].URL)
```

</CodeGroup>

The Go snippet is the body of a function returning `error`, importing `context`, `errors`, `fmt`, `os`, `time`, and `yir "github.com/yir-ai/sdk/go"`. The repository contains a [compile-checked example](https://github.com/yir-ai/sdk/blob/main/go/client_example_test.go).

| Capability | TypeScript | Go |

| Quote | `quoteImage`, `quoteVideo`, `quoteBatch` | `QuoteImage`, `QuoteVideo`, `QuoteBatch` |

## Behavior to know

- **Idempotency keys.** The API requires a key on every generation request. If you omit the key argument, the SDK generates a random one for that call, which protects only that single HTTP call; calling again without a key can create another billable Job. Pass your own persisted key, and reuse it with the exact request to recover after a crash or an unknown outcome. Submit is never retried automatically.
- **Waiting.** `waitForJob` / `WaitJob` poll the status endpoint with back-off (5 s, then 10 s, then 20 s) and read the full Job once at the end. A timeout or abort only stops local waiting; the Job keeps running. Resume with the saved ID.
- **Errors.** API errors expose `status`, `code`, `retryable`, and `action`. A failed or cancelled Job raises `YirJobError` (TypeScript) or `JobError` (Go) carrying the complete Job. Branch on `code`, not on messages. See [error codes](/docs/support/error-codes).
- **Validation.** Local parameter validation needs a model catalog you pass in; otherwise the Gateway validates. See [models and parameters](/docs/guides/models).
- **Parameter notices.** For GPT Image, the SDKs log a warning when `quality` is sent without pinning the official channel, because it will be ignored.

## Upgrading

**TypeScript 0.3.0 / Go 0.4.0.** Waiting now backs off (5 s, then 10 s, then 20 s) instead of polling every 2 seconds; set `pollIntervalMs` / `WaitOptions.PollInterval` to keep a fixed interval. `constructWebhookEvent` / `ConstructWebhookEvent` are new. No call signatures change.

**From 0.1.0.** TypeScript 0.2 and Go 0.2 removed bundled model lists and client-side price tables, and switched waiting to the status endpoint (`onPoll` / `OnPoll` now receive a status summary). Go 0.3.0 made the idempotency key argument variadic. Read the [migration guide](https://github.com/yir-ai/sdk/blob/main/typescript/docs/parameter-contracts.md) before upgrading.

Python is not an official SDK. Use REST from Python; the [Webhooks guide](/docs/guides/webhooks) includes a Python signature check.
