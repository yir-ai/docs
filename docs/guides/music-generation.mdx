---
title: Audio generation
description: Generate songs, instrumentals, sound effects and text-to-speech with the Yir Standard API.
---

Submit audio Jobs (music, sound effects and text-to-speech) to `POST /v1/audio/generations` and quote them with `POST /v1/audio/quotes`. `/v1/music/generations` and `/v1/music/quotes` are the original names of these endpoints and keep working permanently with identical behavior. Audio Jobs follow the same [lifecycle](/docs/concepts/task-lifecycle), [billing](/docs/concepts/billing), [routing](/docs/concepts/routing), and [Webhooks](/docs/production/webhooks) as images and videos. Each Job returns the tracks the model makes per request: one for most models, two for Suno.

## Request fields

| Field | Required | Description |
| --- | --- | --- |
| `model` | Yes | A music, sound-effect or text-to-speech model such as `minimax/music-2.6`. See [models and parameters](/docs/models). |
| `input` | Yes | `{ "type": "text", "prompt": ..., "lyrics": ... }`. `prompt` describes style, mood and scenario, or the sound. `lyrics` uses lines separated by `\n`. Length limits are per model. Suno also takes a `reference` input to [cover an uploaded song](#cover-an-uploaded-song). |
| `parameters` | No | Only what the model's contract declares: `instrumental` and `lyrics_optimizer` (default `false`), `duration` for length-priced models, and `n` (`1`, or `2` for Suno). |
| `max_cost` | No | Optional cap on the Job's charge in USD. See [billing](/docs/concepts/billing#set-a-spending-limit). |
| `routing` | No | See [routing](/docs/concepts/routing). |
| `webhook_url` | No | HTTPS URL that receives the terminal Job. |

Vocal music needs `lyrics`. Set `lyrics_optimizer: true` and omit `lyrics` to have the model write them from the prompt, or set `instrumental: true` and omit both for a track without vocals. Other combinations fail with `400 YIR_INVALID_REQUEST`. Not every model takes every option:

| Model | Lyrics | Length | Tracks per Job |
| --- | --- | --- | --- |
| [MiniMax Music 2.6](/docs/models/minimax/music-2-6) | Own lyrics, auto lyrics or instrumental | Model decides | 1 |
| [MiniMax Music 3](/docs/models/minimax/music-3) | Own lyrics required | Ends with the lyrics, up to 300 s | 1 |
| [ElevenLabs Music v2](/docs/models/elevenlabs/music-v2) and [v2.5](/docs/models/elevenlabs/music-v2-5) | Auto lyrics or instrumental; no own lyrics | `duration`: 30 to 300 s, default 60 | 1 |
| [Suno v6](/docs/models/suno/suno-v6), [v6 Wild](/docs/models/suno/suno-v6-wild) and [v6 Mini](/docs/models/suno/suno-v6-mini) | Own lyrics, auto lyrics or instrumental | Model decides | 2 |

Suno has no official API; Yir accesses the Suno v6 models unofficially through third-party channels. There is no tempo or key control. Prices and billing rules are on each model page.

## Cover an uploaded song

Suno v6, v6 Wild and v6 Mini can cover a song you provide: the result keeps the source melody and remakes it in the style the prompt describes. Send `input.type: "reference"` with exactly one `reference_audio` (a `file_id` from the [Files API](/docs/guides/input-files) or a public HTTPS `url`, up to 8 minutes). Lyrics follow the same rule as above: send new `lyrics`, set `lyrics_optimizer: true`, or set `instrumental: true`. A cover returns two tracks at the same price as basic generation. Other audio models reject reference input with `400 YIR_INVALID_REQUEST`.

```json
{
  "model": "suno/suno-v6",
  "input": {
    "type": "reference",
    "prompt": "Acoustic folk, fingerpicked guitar and a soft female vocal",
    "references": [{ "role": "reference_audio", "file_id": "file_..." }]
  },
  "parameters": { "lyrics_optimizer": true }
}
```

## Sound effects

[ElevenLabs Sound Effects v2](/docs/models/elevenlabs/sound-effects-v2) makes short sound effects through the same endpoints. Send only `input.prompt` (up to 450 characters) and optionally `parameters.duration`, a whole number of seconds from 1 to 22 (default 5); lyrics, `instrumental` and `lyrics_optimizer` are rejected.

```json
{
  "model": "elevenlabs/sound-effects-v2",
  "input": { "type": "text", "prompt": "A heavy wooden door creaking open in an empty stone hall" },
  "parameters": { "duration": 5 }
}
```

## Text-to-speech

[MiniMax Speech 2.8 HD](/docs/models/minimax/speech-2-8-hd) (up to 10000 characters) and [ElevenLabs v3](/docs/models/elevenlabs/eleven-v3) (up to 5000 characters) read `input.prompt` aloud. `parameters` take only `n` (`1`) and `voice`, a preset voice ID of the model; omit it for the model default. The voice does not change the price. Lyrics, `instrumental`, `lyrics_optimizer` and `duration` are rejected. Text-to-speech is priced per character of the prompt, spaces, punctuation and audio tags included, and the quote reports operation `generate_speech`. The Job delivers one MP3.

```json
{
  "model": "minimax/speech-2.8-hd",
  "input": { "type": "text", "prompt": "Good morning. The city is still waking up." },
  "parameters": { "voice": "English_expressive_narrator" }
}
```

## Quote, submit and collect

Quote the request with the same body (without `max_cost` and `webhook_url`) and check `supply.available`:

```bash
curl https://gateway.yir.ai/v1/audio/quotes \
  --header "Authorization: Bearer $YIR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "minimax/music-2.6",
    "input": {
      "type": "text",
      "prompt": "Warm indie folk, acoustic guitar and soft vocals, a quiet morning walk",
      "lyrics": "[Verse]\nMorning light on an empty street\n[Chorus]\nWalk with me, slow and sweet"
    }
  }'
```

Submit it with an `Idempotency-Key`:

```bash
curl https://gateway.yir.ai/v1/audio/generations \
  --header "Authorization: Bearer $YIR_API_KEY" \
  --header "Content-Type: application/json" \
  --header "Idempotency-Key: audio-$(date +%s)" \
  --data '{
    "model": "minimax/music-2.6",
    "input": {
      "type": "text",
      "prompt": "Warm indie folk, acoustic guitar and soft vocals, a quiet morning walk",
      "lyrics": "[Verse]\nMorning light on an empty street\n[Chorus]\nWalk with me, slow and sweet"
    }
  }' | tee job.json

export YIR_JOB_ID="$(jq -r '.id' job.json)"
```

Poll until the Job reaches a terminal state, then download the track:

```bash
while true; do
  status="$(curl --silent https://gateway.yir.ai/v1/jobs/$YIR_JOB_ID/status \
    --header "Authorization: Bearer $YIR_API_KEY" | jq -r '.status')"
  echo "status: $status"
  case "$status" in
    succeeded|failed|cancelled) break ;;
    *) sleep 5 ;;
  esac
done

curl --silent https://gateway.yir.ai/v1/jobs/$YIR_JOB_ID \
  --header "Authorization: Bearer $YIR_API_KEY" > job.json
curl --location --output track.mp3 "$(jq -r '.result.files[0].url' job.json)"
```

## Results

A successful Job returns its audio in `result.files`, one file per track (two for Suno), each with its measured length in `duration_ms`. Most models, including text-to-speech, deliver MP3 (`media_type: "audio/mpeg"`); MiniMax Music 3 delivers WAV (`audio/wav`). The URL is a short-lived signed link; copy the file to your own storage. See [results and retention](/docs/concepts/task-lifecycle#results-and-retention).
