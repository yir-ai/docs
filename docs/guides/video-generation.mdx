---
title: Video generation
description: Generate videos from text, first and last frames, or mixed image, video, and audio references.
---

Submit video Jobs to `POST /v1/videos/generations`. Video Jobs follow the same [lifecycle](/docs/concepts/task-lifecycle), [billing](/docs/concepts/billing), and [routing](/docs/concepts/routing) rules as images, but usually take minutes rather than seconds, so a [Webhook](/docs/guides/webhooks) is often a better fit than polling.

## Input modes

| `input.type` | Use | Reference roles |
| --- | --- | --- |
| `text` | Text to video | None |
| `image` | Animate from a start frame, optionally to an end frame | `first_frame`, `last_frame` |
| `reference` | Guide the video with mixed media | `reference_image`, `reference_video`, `reference_audio` |

Upload all image, video, and audio references through the [Files API](/docs/guides/input-files). Wait for analysis to reach `ready`, then reference each file by `role` and `file_id`. Generation requests reject external URLs.

Which modes, roles, and counts a model accepts is defined in its contract. For example, Seedance 2.0 accepts `first_frame` plus an optional `last_frame` in `image` mode, and in `reference` mode up to 9 images, 3 videos, and 3 audio clips (at least one image or video).

## Common parameters

| Parameter | Description |
| --- | --- |
| `duration` | Output length in seconds, within the model's range. |
| `resolution` | For example `480p`, `720p`, `1080p`. |
| `aspect_ratio` | For example `16:9`, `9:16`, `1:1`, or `adaptive` where supported. |
| `generate_audio` | Generate native audio with the video, where supported. |
| `return_last_frame` | Seedance 2.0 only: also return the final frame as an image. Requires a channel that supports it. |
| `n` | Always `1`. |

Read a model's exact values from `GET /v1/models/{creator}/{model}?view=contract`.

## Quote before you submit

Video prices depend on duration, resolution, audio, and references, so quote the exact request with `POST /v1/videos/quotes` first. A quote that includes video or audio references uses their measured durations. Check `supply.available` and, when `supply.requires_max_cost` is `true`, include `max_cost` on submission.

## Results

A successful video Job returns the video in `result.files`. When you request `return_last_frame`, the last frame is an additional image file. If only that extra file cannot be delivered, the Job still succeeds with `result.warnings: ["additional_results_unavailable"]`.
