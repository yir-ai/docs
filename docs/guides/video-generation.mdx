Submit video Jobs to `POST /v1/videos/generations`. Video Jobs follow the same [lifecycle](/docs/concepts/task-lifecycle), [billing](/docs/concepts/billing), and [routing](/docs/concepts/routing) rules as images, but usually take minutes rather than seconds, so a [Webhook](/docs/production/webhooks) is often a better fit than polling.

## Input modes

| `input.type` | Use | Reference roles |
| --- | --- | --- |
| `text` | Text to video | None |
| `image` | Animate from a start frame, optionally through ordered keyframes to an end frame | `first_frame`, `keyframe`, `last_frame` |
| `reference` | Guide the video with mixed media | `reference_image`, `reference_video`, `reference_audio` |

Reference each image, video, or audio input by `role` plus either a `file_id` from the [Files API](/docs/guides/input-files) (wait for `ready` first) or a public HTTPS `url` that Yir downloads at submission. See [input files](/docs/guides/input-files#public-urls) for URL limits.

Which modes, roles, and counts a model accepts is defined in its contract. For example, Seedance 2.0 accepts `first_frame` plus an optional `last_frame` in `image` mode, and in `reference` mode up to 9 images, 3 videos, and 3 audio clips (at least one image or video). Kling 4.0 also accepts up to 8 `keyframe` references in `image` mode; keyframes play in the order they appear in `references`.

## Genjutsu motion transfer and object swap

Choose the operation with `model` and use `input.type: "reference"` on `POST /v1/videos/generations`. The model ID selects the mode automatically.

| Operation | Yir model ID | What the reference images show | Source MP4 | Output resolution |
| --- | --- | --- | --- | --- |
| Motion transfer | [`nanoapi/genjutsu-1.0`](/docs/models/higgsfield/genjutsu/motion-transfer) | The person who should perform the movements from the source video | 1–30 seconds | `480p`, `720p`, `1080p` |
| Object swap | [`higgsfield/genjutsu-1.0-object-swap`](/docs/models/higgsfield/genjutsu/object-swap) | The replacement object to insert into the source video | 4–30 seconds | `480p`, `720p`, `1080p` |
| Genjutsu Light object swap | [`higgsfield/genjutsu-lite-1.0`](/docs/models/higgsfield/genjutsu-light/object-swap) | The replacement object to insert into the source video | 4–30 seconds | `720p`, `1080p` |

All three accept exactly one `reference_video` and 1–10 `reference_image` inputs. The default is `720p`. The Standard API accepts an optional prompt of up to 5,000 characters. If your SDK requires a prompt, use one like the examples below. For a numeric quote, upload the source MP4 with the [Files API](/docs/guides/input-files) and use its ready `file_id`.

In an object-swap prompt, `@video_1` refers to the source video and `@image_1`, `@image_2`, and so on refer to the replacement images in their order in `references`. Use `higgsfield/genjutsu-lite-1.0` in the same request for Lite. Replace the example file IDs with your own ready files.

## Common parameters

| Parameter | Description |
| --- | --- |
| `duration` | Output length in seconds, within the model's range, or `"auto"` for supported reference-video edits. Quote and Job preserve `"auto"`; URL quotes may have available supply without a known amount. See [Seedance 2.5](/docs/models/bytedance/seedance-2-5). |
| `task_type` | Seedance 2.5 `reference` mode only: `auto` (default), `reference`, `edit` or `extend`. See [Seedance 2.5](/docs/models/bytedance/seedance-2-5). |
| `resolution` | For example `480p`, `720p`, `1080p`. |
| `aspect_ratio` | For example `16:9`, `9:16`, `1:1`, or `adaptive` where supported. |
| `generate_audio` | Generate native audio with the video, where supported. |
| `return_last_frame` | Seedance 2.0 only: also return the final frame as an image. Requires a channel that supports it. |
| `n` | Always `1`. |

Read a model's exact values from `GET /v1/models/{creator}/{model}?view=contract`.

## Quote before you submit

Video prices depend on duration, resolution, audio, and references, so quote the exact request with `POST /v1/videos/quotes` first. A quote that includes uploaded (`file_id`) video or audio references uses their measured durations. Yir does not download `url` references to quote, so for Seedance 2.0, 2.0 Fast, 2.0 Mini, 2.5, MiniMax H3 and H3 Max you can add `duration_seconds` to a `url` reference_video or reference_audio: the quote prices input media from your value and returns `input_duration_source: "declared"`. Without it, a `url` reference video has no complete price. Submission ignores `duration_seconds`; the Job is admitted and charged by the duration measured after import. Check `supply.available`. The quoted price is an estimate and the final charge follows the actual cost; add `max_cost` on submission if you need a cap.

Kling Motion Control (`reference_image` + `reference_video`) is priced by the measured length of the reference video, rounded down to whole seconds; the requested `duration` does not change the price. Upload the reference video and pass its `file_id` to get a quoted amount. A URL reference has no amount, so a request with `max_cost` is rejected. See [quotes and billing](/docs/concepts/billing).

## Results

A successful video Job returns the video in `result.files`. When you request `return_last_frame`, the last frame is an additional image file. If only that extra file cannot be delivered, the Job still succeeds with `result.warnings: ["additional_results_unavailable"]`.
