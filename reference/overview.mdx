YIR API references are generated from OpenAPI files maintained in this repository.

The first public reference covers the KIE-compatible gateway routes:

- `POST /x-router/kie/api/v1/jobs/createTask`
- `GET /x-router/kie/api/v1/jobs/recordInfo`

YIR uses `X-YIR-API-Key` for gateway authentication and keeps `Authorization` reserved for the upstream provider.

Use the KIE-compatible API section in the sidebar for request and response details.
