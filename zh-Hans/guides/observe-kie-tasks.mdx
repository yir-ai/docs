Observe 是最安全的第一步，因为它保持原 provider 链路不变。

## 会记录什么

- task 创建时间
- task 状态变化
- 上游错误
- 总耗时
- 成本估算信号
- URL metadata

## Observe 不做什么

- 不切换 provider
- 不启动 fallback attempt
- 不把 base64 或 multipart 输入物化到 YIR storage
- 不镜像 provider 结果

积累足够健康 baseline 后，再基于真实延迟和成本数据评估 Protect、Optimize 或 Accelerate。
