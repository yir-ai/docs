YIR API Reference 由本仓库维护的 OpenAPI 文件生成。

第一版公开 reference 覆盖 KIE-compatible gateway 路由：

- `POST /x-router/kie/api/v1/jobs/createTask`
- `GET /x-router/kie/api/v1/jobs/recordInfo`

YIR 使用 `X-YIR-API-Key` 做 gateway 鉴权，并把 `Authorization` 保留给上游 provider。

请在侧边栏的 KIE-compatible API 区域查看请求和响应细节。
