---
title: "鉴权"
description: "YIR 使用独立 Header 鉴权，不占用上游 Authorization。"
---

YIR source-compatible 路由使用两组凭据：

| Header | 所属方 | 用途 |
| --- | --- | --- |
| `X-YIR-API-Key` | YIR | 鉴权当前 gateway 请求。 |
| `Authorization` | 上游 provider | 原样传给上游，或加密保存用于上游 attempt。 |

YIR 不用 `Authorization` 做 gateway 鉴权，因为很多 source-compatible provider 已经使用这个 Header。拆开后，用户迁移时只需要改 base URL 和加一个 YIR Header。

```bash
curl https://api.yir.ai/x-router/kie/api/v1/jobs/createTask \
  -H "X-YIR-API-Key: yir_sk_..." \
  -H "Authorization: Bearer <upstream_kie_key>" \
  -H "Content-Type: application/json" \
  -d @request.json
```

缺少或错误的 `X-YIR-API-Key` 会被 YIR 拒绝。若某个上游路径需要原上游 key，但请求没有提供，YIR 不会创建任务。
