---
title: "异步任务"
description: "YIR 如何追踪长耗时多模态生成任务。"
---

长耗时生成任务不应该依赖一条同步连接。YIR 把每次生成建模为一个 task 和一个或多个 attempt。

```text
Client request
  -> YIR task
  -> provider attempt
  -> provider task
  -> polling or webhook
  -> winning result
  -> source-compatible response or callback
```

YIR 会追踪：

- source-compatible 请求
- YIR task 状态
- 每个 provider attempt
- 上游 provider task id
- polling 和 webhook 结果
- winning attempt
- late result
- callback 投递
- 估算和实际成本信号

这套状态模型让 Observe、Protect、Optimize 和 Accelerate 都可追踪、可审计。
