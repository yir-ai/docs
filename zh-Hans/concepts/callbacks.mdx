---
title: "Callbacks"
description: "接收 YIR 投递的 source-compatible 任务完成事件。"
---

当任务由 YIR 托管时，YIR 负责投递 source-compatible callback。

YIR 会使用稳定 event id 和 HMAC 签名投递托管 callback。请保存 event id，并把重复投递视为同一事件的重试。

Callback URL 必须使用支持的公网 URL scheme，不能解析到 loopback、private、link-local、localhost 或单标签内网主机名。YIR 会拒绝不安全 callback 目标，而不是无限重试。

Callback 会携带稳定 event id 重试。你的 endpoint 应该支持幂等处理。
